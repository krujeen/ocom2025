บทที่ 9.6: การเปรียบเทียบด้วยเงื่อนไขประกอบ

การเรียนรู้ตัวดำเนินการทางตรรกศาสตร์และการสร้างเงื่อนไขที่ซับซ้อน

เนื้อหาในบทเรียน

  • 9.6.1 ตัวดำเนินการทางตรรกศาสตร์ (Logical Operators)
  • 9.6.2 ลำดับความสำคัญของตัวดำเนินการ
  • 9.6.3 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ
  • 9.6.4 ตัวอย่างข้อสอบฝึกทำ

ในบทเรียนนี้ เราจะมาเรียนรู้เกี่ยวกับ การเปรียบเทียบด้วยเงื่อนไขประกอบ (Compound Conditions) โดยใช้ตัวดำเนินการทางตรรกศาสตร์ (not, and, or) ในภาษา Python ซึ่งช่วยให้เราสามารถสร้างเงื่อนไขที่ซับซ้อนและหลากหลายขึ้นในการควบคุมการทำงานของโปรแกรม

9.6.1 ตัวดำเนินการทางตรรกศาสตร์ (Logical Operators)

ตัวดำเนินการทางตรรกศาสตร์ใช้เพื่อเชื่อมโยงหรือปรับเปลี่ยนนิพจน์เปรียบเทียบ (ซึ่งให้ผลลัพธ์เป็น True หรือ False) เพื่อสร้างเงื่อนไขที่ซับซ้อนยิ่งขึ้น ผลลัพธ์ของตัวดำเนินการเหล่านี้จะเป็นค่าบูลีน (True หรือ False) เสมอ

ก. and (และ)

ความหมาย

นิพจน์ที่เชื่อมด้วย and จะให้ผลลัพธ์เป็น True ก็ต่อเมื่อ นิพจน์ย่อยทั้งสองฝั่งเป็น True ทั้งคู่ เท่านั้น กรณีอื่นจะให้ผลลัพธ์เป็น False

ตารางค่าความจริง:

Condition1 Condition2 Condition1 and Condition2
TrueTrueTrue
TrueFalseFalse
FalseTrueFalse
FalseFalseFalse

ตัวอย่าง

(age > 18) and (has_license == True) จะเป็น True ก็ต่อเมื่อ age มากกว่า 18 และ has_license เป็น True ทั้งสองเงื่อนไข

ข. or (หรือ)

ความหมาย

นิพจน์ที่เชื่อมด้วย or จะให้ผลลัพธ์เป็น False ก็ต่อเมื่อ นิพจน์ย่อยทั้งสองฝั่งเป็น False ทั้งคู่ เท่านั้น กรณีอื่นจะให้ผลลัพธ์เป็น True

ตารางค่าความจริง:

Condition1 Condition2 Condition1 or Condition2
TrueTrueTrue
TrueFalseTrue
FalseTrueTrue
FalseFalseFalse

ตัวอย่าง

(score >= 80) or (attendance >= 90) จะเป็น True ถ้า score มากกว่าหรือเท่ากับ 80 หรือ attendance มากกว่าหรือเท่ากับ 90 อย่างน้อยหนึ่งเงื่อนไข (หรือทั้งสองเงื่อนไข)

ค. not (นิเสธ)

ความหมาย

not ใช้เพื่อกลับค่าความจริงของนิพจน์ที่อยู่ด้านหลัง (จาก True เป็น False และจาก False เป็น True)

ตารางค่าความจริง:

Condition not Condition
TrueFalse
FalseTrue

ตัวอย่าง

not (is_raining == True) จะเป็น True ถ้า is_raining เป็น False (ไม่ฝนตก)

9.6.2 ลำดับความสำคัญของตัวดำเนินการ (Operator Precedence)

เมื่อมีตัวดำเนินการหลายตัวในนิพจน์เดียวกัน Python จะประมวลผลตามลำดับความสำคัญ:

ลำดับความสำคัญ (จากสูงไปต่ำ)

  1. วงเล็บ (): คำนวณสิ่งที่อยู่ในวงเล็บก่อนเสมอ
  2. ตัวดำเนินการทางคณิตศาสตร์ (+, -, *, /, **, //, %)
  3. ตัวดำเนินการเปรียบเทียบ (==, !=, <, <=, >, >=)
  4. not
  5. and
  6. or

ตัวอย่าง

not score > 50 and age < 18

  1. score > 50 (เปรียบเทียบ)
  2. age < 18 (เปรียบเทียบ)
  3. not (กลับค่าของ score > 50)
  4. and (เชื่อมผลลัพธ์ของ not กับ age < 18)

9.6.3 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ

เอกสารนี้รวบรวมตัวอย่างโจทย์พื้นฐานสำหรับการทำความเข้าใจตัวดำเนินการทางตรรกศาสตร์และการสร้างเงื่อนไขประกอบ เพื่อเตรียมความพร้อมสำหรับการสอบ สอวน. คอมพิวเตอร์ครับ

โจทย์ข้อที่ 1: การใช้ and

คำถาม: กำหนดให้ x = 10, y = 5 จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

(x > 5) and (y < 10)

แนวคิด

  • ประเมินค่าของแต่ละนิพจน์เปรียบเทียบในวงเล็บก่อน
  • ใช้กฎของ and เพื่อหาผลลัพธ์สุดท้าย

เฉลย

  1. (x > 5): 10 > 5 คือ True
  2. (y < 10): 5 < 10 คือ True
  3. True and True คือ True

คำตอบ: True

โจทย์ข้อที่ 2: การใช้ or

คำถาม: กำหนดให้ temp = 30, is_sunny = False จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

(temp > 25) or (is_sunny == True)

แนวคิด

  • ประเมินค่าของแต่ละนิพจน์เปรียบเทียบ
  • ใช้กฎของ or เพื่อหาผลลัพธ์สุดท้าย

เฉลย

  1. (temp > 25): 30 > 25 คือ True
  2. (is_sunny == True): False == True คือ False
  3. True or False คือ True

คำตอบ: True

โจทย์ข้อที่ 3: การใช้ not

คำถาม: กำหนดให้ has_permission = False จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

not has_permission

แนวคิด

  • ใช้กฎของ not เพื่อกลับค่าความจริง

เฉลย

not False คือ True

คำตอบ: True

โจทย์ข้อที่ 4: การผสมผสาน not, and, or

คำถาม: กำหนดให้ age = 16, has_id = True จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

(age >= 18) or (not has_id)

แนวคิด

  • ประเมินค่าของแต่ละนิพจน์เปรียบเทียบ
  • ทำ not ก่อน
  • ใช้กฎของ or

เฉลย

  1. (age >= 18): 16 >= 18 คือ False
  2. (not has_id): not True คือ False
  3. False or False คือ False

คำตอบ: False

โจทย์ข้อที่ 5: การประเมินนิพจน์ที่ซับซ้อนขึ้น

คำถาม: กำหนดให้ score = 85, attendance = 90 จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

(score > 90 and attendance >= 90) or (score >= 80 and attendance < 90)

แนวคิด

  • ประเมินนิพจน์ในวงเล็บแต่ละชุดก่อน
  • ทำ and ก่อนในแต่ละวงเล็บ
  • สุดท้ายใช้ or

เฉลย

วงเล็บแรก: (score > 90 and attendance >= 90)

  1. score > 90: 85 > 90 คือ False
  2. attendance >= 90: 90 >= 90 คือ True
  3. False and True คือ False

วงเล็บที่สอง: (score >= 80 and attendance < 90)

  1. score >= 80: 85 >= 80 คือ True
  2. attendance < 90: 90 < 90 คือ False
  3. True and False คือ False

เชื่อมด้วย or: False or False คือ False

คำตอบ: False

9.6.4 ตัวอย่างข้อสอบฝึกทำ

เอกสารนี้รวบรวมตัวอย่างข้อสอบสำหรับนักเรียนได้ฝึกทำในหัวข้อ "การเปรียบเทียบด้วยเงื่อนไขประกอบ" เพื่อเสริมสร้างความเข้าใจและเตรียมความพร้อมสำหรับการสอบ สอวน. คอมพิวเตอร์ครับ

โจทย์ข้อที่ 6: การใช้ and

คำถาม: กำหนดให้ a = 5, b = 10 จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

(a < b) and (a + b == 15)

แนวคิด

  • ประเมินแต่ละส่วนแล้วใช้ and

เฉลย

  1. (a < b): 5 < 10 คือ True
  2. (a + b == 15): 5 + 10 == 15 → 15 == 15 คือ True
  3. True and True คือ True

คำตอบ: True

โจทย์ข้อที่ 7: การใช้ or

คำถาม: กำหนดให้ is_weekend = False, is_holiday = True จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

is_weekend or is_holiday

แนวคิด

  • ประเมินแต่ละส่วนแล้วใช้ or

เฉลย

  1. is_weekend: False
  2. is_holiday: True
  3. False or True คือ True

คำตอบ: True

โจทย์ข้อที่ 8: การใช้ not

คำถาม: กำหนดให้ is_active = True จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

not (is_active == False)

แนวคิด

  • ประเมินวงเล็บในสุดก่อน
  • ทำ not

เฉลย

  1. (is_active == False): True == False คือ False
  2. not (False): not False คือ True

คำตอบ: True

โจทย์ข้อที่ 9: การผสมผสาน not และ and

คำถาม: กำหนดให้ temp = 15, is_cold = True จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

not (temp > 20) and is_cold

แนวคิด

  • เปรียบเทียบก่อน
  • ทำ not
  • ทำ and

เฉลย

  1. (temp > 20): 15 > 20 คือ False
  2. not (False): not False คือ True
  3. True and is_cold: True and True คือ True

คำตอบ: True

โจทย์ข้อที่ 10: การผสมผสาน and และ or

คำถาม: กำหนดให้ x = 20, y = 30, z = 40 จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

(x < y and y < z) or (x == z)

แนวคิด

  • ทำ and ก่อน
  • ทำ or

เฉลย

วงเล็บแรก: (x < y and y < z)

  1. x < y: 20 < 30 คือ True
  2. y < z: 30 < 40 คือ True
  3. True and True คือ True

วงเล็บที่สอง: (x == z)

  1. x == z: 20 == 40 คือ False

เชื่อมด้วย or: True or False คือ True

คำตอบ: True
