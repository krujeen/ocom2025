บทที่ 9.7: ลำดับการทำงานวนซ้ำด้วยลูป while

การเรียนรู้โครงสร้างควบคุมแบบวนซ้ำและการใช้งานลูป while

ในบทเรียนนี้ เราจะมาเรียนรู้เกี่ยวกับ ลำดับการทำงานแบบวนซ้ำ (Repetitive Execution) โดยใช้คำสั่ง while loop ในภาษา Python ซึ่งเป็นโครงสร้างควบคุมที่ช่วยให้โปรแกรมสามารถทำชุดคำสั่งเดิมซ้ำๆ ได้ตราบเท่าที่เงื่อนไขที่กำหนดเป็นจริง การวนซ้ำเป็นสิ่งจำเป็นสำหรับการประมวลผลข้อมูลจำนวนมาก การทำซ้ำงานเดิมๆ และการสร้างโปรแกรมที่มีประสิทธิภาพ

9.7.1 การทำงานแบบวนซ้ำ (Repetitive Execution / Iteration)

การทำงานแบบวนซ้ำ คือ การที่โปรแกรมจะประมวลผลคำสั่งชุดเดิมซ้ำๆ หลายครั้ง โดยปกติแล้วการวนซ้ำจะเกิดขึ้นภายใต้เงื่อนไขบางอย่าง หรือทำซ้ำตามจำนวนครั้งที่กำหนด

แนวคิดหลัก

"ตราบใดที่เงื่อนไขนี้เป็นจริง, ให้ทำสิ่งนั้นซ้ำไปเรื่อยๆ"

ประโยชน์

  • ลดความจำเป็นในการเขียนโค้ดซ้ำๆ
  • จัดการกับข้อมูลจำนวนมากได้อย่างมีประสิทธิภาพ

9.7.2 ลูป while (while Loop)

ลูป while เป็นโครงสร้างการวนซ้ำที่โปรแกรมจะตรวจสอบเงื่อนไขก่อนที่จะทำชุดคำสั่งในแต่ละรอบ หากเงื่อนไขเป็นจริง โปรแกรมจะทำชุดคำสั่งในบล็อกของลูป จากนั้นจะกลับไปตรวจสอบเงื่อนไขอีกครั้ง ทำซ้ำเช่นนี้ไปเรื่อยๆ จนกว่าเงื่อนไขจะเป็นเท็จ โปรแกรมจึงจะออกจากลูปและทำคำสั่งถัดไป

รูปแบบในภาษา Python

while condition:
    # คำสั่งที่จะทำซ้ำตราบเท่าที่ condition เป็น True
    # (ต้องมี indent หรือการเยื้อง)
    # ควรมีคำสั่งที่ทำให้ condition เป็น False ในที่สุด

องค์ประกอบสำคัญของลูป while:

  1. การกำหนดค่าเริ่มต้น (Initialization): ตัวแปรที่ใช้ในเงื่อนไขของลูปมักจะต้องมีการกำหนดค่าเริ่มต้นก่อนเข้าลูป
  2. เงื่อนไข (Condition): นิพจน์เปรียบเทียบที่ให้ผลลัพธ์เป็น True หรือ False ลูปจะทำงานตราบใดที่เงื่อนไขเป็น True
  3. การอัปเดต (Update): ภายในบล็อกของลูป ต้องมีคำสั่งที่เปลี่ยนแปลงค่าของตัวแปรที่ใช้ในเงื่อนไข เพื่อให้เงื่อนไขสามารถเป็น False ได้ในที่สุด มิฉะนั้นจะเกิด ลูปไม่รู้จบ (Infinite Loop)

9.7.3 ตัวอย่างการทำงานของลูป while

ตัวอย่างที่ 1: นับเลขขึ้น

โค้ด

count = 1
while count <= 5:
    print(count)
    count = count + 1 # หรือ count += 1
print("จบการนับ")

คำอธิบาย

  1. count = 1 (กำหนดค่าเริ่มต้น)
  2. รอบที่ 1: count <= 5 (1 <= 5) เป็น True
    • print(count) → แสดงผล 1
    • count = 2 (อัปเดตค่า)
  3. รอบที่ 2: count <= 5 (2 <= 5) เป็น True
    • print(count) → แสดงผล 2
    • count = 3
  4. รอบที่ 3: count <= 5 (3 <= 5) เป็น True
    • print(count) → แสดงผล 3
    • count = 4
  5. รอบที่ 4: count <= 5 (4 <= 5) เป็น True
    • print(count) → แสดงผล 4
    • count = 5
  6. รอบที่ 5: count <= 5 (5 <= 5) เป็น True
    • print(count) → แสดงผล 5
    • count = 6
  7. รอบที่ 6: count <= 5 (6 <= 5) เป็น False
    • ออกจากลูป
  8. print("จบการนับ") → แสดงผล "จบการนับ"

ตัวอย่างที่ 2: การหาผลรวม

โค้ด

total = 0
num = 1
while num <= 5:
    total = total + num
    num = num + 1
print("ผลรวมคือ:", total)

คำอธิบาย

  1. total = 0, num = 1 (กำหนดค่าเริ่มต้น)
  2. รอบที่ 1: num <= 5 (1 <= 5) เป็น True
    • total = 0 + 1 = 1
    • num = 2
  3. รอบที่ 2: num <= 5 (2 <= 5) เป็น True
    • total = 1 + 2 = 3
    • num = 3
  4. รอบที่ 3: num <= 5 (3 <= 5) เป็น True
    • total = 3 + 3 = 6
    • num = 4
  5. รอบที่ 4: num <= 5 (4 <= 5) เป็น True
    • total = 6 + 4 = 10
    • num = 5
  6. รอบที่ 5: num <= 5 (5 <= 5) เป็น True
    • total = 10 + 5 = 15
    • num = 6
  7. รอบที่ 6: num <= 5 (6 <= 5) เป็น False
    • ออกจากลูป
  8. print("ผลรวมคือ:", total) → แสดงผล "ผลรวมคือ: 15"

9.7.4 ข้อควรระวัง: ลูปไม่รู้จบ (Infinite Loop)

ลูปไม่รู้จบเกิดขึ้นเมื่อเงื่อนไขของลูป while เป็น True เสมอ และไม่มีทางเปลี่ยนเป็น False ได้ ทำให้โปรแกรมทำงานซ้ำไปเรื่อยๆ ไม่มีที่สิ้นสุด

ตัวอย่างลูปไม่รู้จบ

# ตัวอย่างลูปไม่รู้จบ
x = 10
while x > 0:
    print("Looping...")
    # ไม่มีคำสั่งที่ทำให้ x มีค่าน้อยลงหรือเงื่อนไขเป็น False

วิธีแก้ไข

ตรวจสอบให้แน่ใจว่ามีคำสั่งอัปเดตค่าตัวแปรที่เกี่ยวข้องกับเงื่อนไขในแต่ละรอบของลูป และคำสั่งนั้นทำให้เงื่อนไขเป็นเท็จได้ในที่สุด

คำถาม: กำหนดรหัส Python

i = 1
while i <= 5:
    print("Hello")
    # i = i + 0

รหัสนี้จะทำงานอย่างไร? (ลูปไม่รู้จบหรือไม่) ถ้าไม่รู้จบเพราะอะไร?

แนวคิด

  • ตรวจสอบว่าตัวแปรที่ใช้ในเงื่อนไขมีการเปลี่ยนแปลงที่ทำให้เงื่อนไขเป็นเท็จได้หรือไม่

เฉลย

รหัสนี้จะทำงานเป็น ลูปไม่รู้จบ (Infinite Loop)

เหตุผล: ตัวแปร i ถูกกำหนดค่าเริ่มต้นเป็น 1 และเงื่อนไขคือ i <= 5 ซึ่งเป็นจริงเสมอ เพราะไม่มีคำสั่งใดๆ ในบล็อกของลูปที่จะเปลี่ยนแปลงค่าของ i ทำให้ i มีค่าเป็น 1 ตลอดไป เงื่อนไข 1 <= 5 จึงเป็นจริงตลอดเวลา ทำให้ลูปทำงานซ้ำๆ ไม่มีที่สิ้นสุด

คำตอบ: ลูปไม่รู้จบ, เพราะตัวแปร i ไม่มีการเปลี่ยนแปลงค่าภายในลูป ทำให้เงื่อนไข i <= 5 เป็นจริงตลอดไป

โจทย์ข้อที่ 10: การระบุลูปไม่รู้จบ (การเปลี่ยนแปลงค่า)

รหัสนี้จะทำงานอย่างไร? (ลูปไม่รู้จบหรือไม่) ถ้าไม่รู้จบเพราะอะไร?

แนวคิด

  • ตรวจสอบว่าค่าของ x มีการเปลี่ยนแปลงที่ทำให้เงื่อนไข x < 5 เป็นเท็จได้ในที่สุดหรือไม่

เฉลย

รหัสนี้จะทำงานเป็น ลูปไม่รู้จบ (Infinite Loop)

เหตุผล: แม้ว่า x จะมีการเปลี่ยนแปลงค่าในแต่ละรอบ (x = x + 1 แล้ว x = x - 1) แต่ผลลัพธ์สุดท้ายคือ x กลับไปมีค่าเดิมเสมอ (x จะเป็น 0 ตลอด) ทำให้เงื่อนไข x < 5 (0 < 5) เป็นจริงตลอดเวลา ลูปจึงทำงานซ้ำๆ ไม่มีที่สิ้นสุด

คำตอบ: ลูปไม่รู้จบ, เพราะค่าของ x ไม่มีการเปลี่ยนแปลงสุทธิ ทำให้เงื่อนไขของลูปเป็นจริงตลอดไป
