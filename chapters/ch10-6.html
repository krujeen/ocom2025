ในบทเรียนนี้ เราจะมาทำความเข้าใจเกี่ยวกับ แนวคิดกราฟพื้นฐาน (Basic Graph Concepts) ซึ่งเป็นโครงสร้างข้อมูลที่สำคัญอย่างยิ่งในวิทยาการคอมพิวเตอร์และคณิตศาสตร์เชิงแยกส่วน กราฟใช้ในการจำลองความสัมพันธ์ระหว่างวัตถุต่างๆ เช่น เครือข่ายสังคม, ถนนในเมือง, วงจรไฟฟ้า หรือการเชื่อมต่อของคอมพิวเตอร์ การเข้าใจกราฟช่วยให้เราสามารถแก้ปัญหาเกี่ยวกับการเดินทาง, การเชื่อมโยง, และการจัดสรรทรัพยากรได้อย่างมีประสิทธิภาพ ซึ่งมักพบในข้อสอบ สอวน. คอมพิวเตอร์

10.6.1 กราฟคืออะไร? (What is a Graph?)

กราฟ (Graph) คือ โครงสร้างทางคณิตศาสตร์ที่ประกอบด้วย:

1. จุดยอด (Vertices / Nodes):

สิ่งที่ถูกจำลอง เช่น เมือง, คน, คอมพิวเตอร์ (นิยมใช้สัญลักษณ์ V)

2. เส้นเชื่อม (Edges / Links):

ความสัมพันธ์หรือการเชื่อมต่อระหว่างจุดยอด เช่น ถนน, มิตรภาพ, สายเคเบิล (นิยมใช้สัญลักษณ์ E)

กราฟหนึ่งๆ มักจะเขียนแทนด้วย G=(V,E)

ตัวอย่าง:

    A ---- B
    |      |
    |      |
    C ---- D

จุดยอด V = {A, B, C, D}

เส้นเชื่อม E = {{A,B}, {A,C}, {B,D}, {C,D}}

10.6.2 ประเภทของกราฟ (Types of Graphs)

กราฟสามารถแบ่งออกได้หลายประเภทตามลักษณะของเส้นเชื่อม:

ก. กราฟไม่มีทิศทาง (Undirected Graph)

  • เส้นเชื่อมไม่มีทิศทาง หมายความว่าการเชื่อมต่อระหว่างจุดยอด u และ v เป็นแบบสองทาง
  • ถ้าไปจาก u ไป v ได้ ก็ไปจาก v ไป u ได้
  • เส้นเชื่อมแทนด้วยคู่ของจุดยอด {u,v}
    A ---- B
    |      |
    C ---- D

ข. กราฟมีทิศทาง (Directed Graph / Digraph)

  • เส้นเชื่อมมีทิศทาง หมายความว่าการเชื่อมต่อจากจุดยอด u ไป v อาจไม่เหมือนกับการเชื่อมต่อจาก v ไป u
  • เส้นเชื่อมแทนด้วยคู่อันดับ (u,v) โดยที่ลูกศรแสดงทิศทาง
    A ----> B
    ^       |
    |       v
    C <---- D

ค. กราฟถ่วงน้ำหนัก (Weighted Graph)

  • เส้นเชื่อมมี "น้ำหนัก" หรือ "ค่าใช้จ่าย" กำกับอยู่ ซึ่งอาจแทนระยะทาง, เวลา, หรือต้นทุน
  • สามารถเป็นได้ทั้งกราฟมีทิศทางและไม่มีทิศทาง
    A --5-- B
    |3      |2
    C --4-- D

10.6.3 การเดินทางบนกราฟ (Graph Traversal)

การเดินทางบนกราฟคือการสำรวจเส้นทางจากจุดยอดหนึ่งไปยังอีกจุดยอดหนึ่ง

ก. ทางเดิน (Path)

  • ทางเดิน (Path): คือ ลำดับของจุดยอดที่เชื่อมต่อกันด้วยเส้นเชื่อม
  • ความยาวของทางเดิน: คือ จำนวนเส้นเชื่อมในทางเดินนั้น
  • ทางเดินอย่างง่าย (Simple Path): ทางเดินที่ไม่มีจุดยอดซ้ำกัน

ตัวอย่าง: ในกราฟ A-B-C-D

  • A → B → C เป็นทางเดิน
  • ความยาว 2

ข. วงจร (Cycle)

  • วงจร (Cycle): คือ ทางเดินที่เริ่มต้นและสิ้นสุดที่จุดยอดเดียวกัน และไม่มีเส้นเชื่อมหรือจุดยอดซ้ำกัน

ตัวอย่าง: ในกราฟ A-B-C-A

  • A → B → C → A เป็นวงจร

10.6.4 การเชื่อมโยง (Connectivity)

การเชื่อมโยงบอกว่าจุดยอดต่างๆ ในกราฟสามารถเข้าถึงกันได้หรือไม่

ก. กราฟเชื่อมโยง (Connected Graph)

ในกราฟไม่มีทิศทาง ถ้าทุกๆ คู่ของจุดยอดสามารถเดินทางถึงกันได้ (มีทางเดินระหว่างกัน) กราฟนั้นจะเรียกว่ากราฟเชื่อมโยง

ข. กราฟไม่เชื่อมโยง (Disconnected Graph)

กราฟที่ไม่เชื่อมโยงกันทั้งหมด นั่นคือมีอย่างน้อยหนึ่งคู่ของจุดยอดที่ไม่สามารถเดินทางถึงกันได้

ค. ส่วนประกอบที่เชื่อมโยง (Connected Components)

ส่วนประกอบที่เชื่อมโยงคือส่วนย่อยๆ ของกราฟไม่เชื่อมโยง ที่ภายในส่วนนั้นๆ ทุกจุดเชื่อมโยงถึงกัน

ง. เส้นทางที่สั้นที่สุด (Shortest Path)

คือทางเดินระหว่างสองจุดยอดที่มีความยาวน้อยที่สุด (สำหรับกราฟถ่วงน้ำหนัก คือผลรวมน้ำหนักน้อยที่สุด)

10.6.5 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ

โจทย์ข้อที่ 1: การระบุส่วนประกอบและประเภทกราฟ

คำถาม: กำหนดกราฟดังรูป:

    A ---- B
    |      |
    |      |
    C ---- D

จงระบุ:

  • ก. จุดยอดทั้งหมด
  • ข. เส้นเชื่อมทั้งหมด
  • ค. กราฟนี้เป็นกราฟมีทิศทางหรือไม่มีทิศทาง?

แนวคิด

  • จุดยอดคือวงกลมหรือจุดต่างๆ
  • เส้นเชื่อมคือเส้นที่เชื่อมระหว่างจุดยอด
  • ดูว่าเส้นเชื่อมมีลูกศรหรือไม่

เฉลย

ก. จุดยอดทั้งหมด: {A,B,C,D}

ข. เส้นเชื่อมทั้งหมด: {{A,B},{A,C},{B,D},{C,D}} (ใช้ปีกกาคู่แสดงเส้นเชื่อมไม่มีทิศทาง)

ค. กราฟนี้เป็น กราฟไม่มีทิศทาง (เพราะไม่มีลูกศรบนเส้นเชื่อม)

โจทย์ข้อที่ 2: การหาทางเดินและวงจร

คำถาม: กำหนดกราฟดังรูป:

    A ----> B
    ^       |
    |       v
    C <---- D

จงระบุ:

  • ก. ทางเดินจาก A ไป D
  • ข. วงจรทั้งหมดในกราฟนี้

แนวคิด

  • ทางเดินต้องตามทิศทางของลูกศร
  • วงจรคือทางเดินที่กลับมาจุดเดิม

เฉลย

ก. ทางเดินจาก A ไป D:

  • A → B → D

ข. วงจรทั้งหมด:

  • A → B → D → C → A

โจทย์ข้อที่ 3: การตรวจสอบการเชื่อมโยง

คำถาม: กำหนดกราฟดังรูป:

    A ---- B ---- C
    
    D ---- E ---- F

กราฟนี้เป็นกราฟเชื่อมโยงหรือไม่? ถ้าไม่เชื่อมโยง มีส่วนประกอบที่เชื่อมโยงกี่ส่วน?

แนวคิด

  • กราฟเชื่อมโยงคือทุกจุดสามารถไปถึงกันได้
  • ส่วนประกอบที่เชื่อมโยงคือกลุ่มของจุดที่เชื่อมถึงกันภายในกลุ่มนั้น

เฉลย

กราฟนี้ ไม่เป็นกราฟเชื่อมโยง

มีส่วนประกอบที่เชื่อมโยง 2 ส่วน ได้แก่:

  • ส่วนที่ 1: {A,B,C}
  • ส่วนที่ 2: {D,E,F}

โจทย์ข้อที่ 4: การหาเส้นทางที่สั้นที่สุด (กราฟถ่วงน้ำหนัก)

คำถาม: จากแผนที่เมือง A, B, C, D ดังรูป (ตัวเลขบนเส้นคือระยะทาง) จงหาเส้นทางที่สั้นที่สุดจากเมือง A ไปเมือง D

     A ---5--- B
     |         |
     2         3
     |         |
     C ---6--- D

แนวคิด

  • ไล่เส้นทางที่เป็นไปได้ทั้งหมดจาก A ไป D และคำนวณระยะทางรวม
  • เลือกเส้นทางที่มีระยะทางน้อยที่สุด

เฉลย

เส้นทางที่เป็นไปได้จาก A ไป D:

  1. A → B → D: ระยะทาง: 5+3=8
  2. A → C → D: ระยะทาง: 2+6=8

ในกรณีนี้มีเส้นทางที่สั้นที่สุด 2 เส้นทางที่มีระยะทางเท่ากันคือ 8

คำตอบ: A → B → D (ระยะทาง 8) หรือ A → C → D (ระยะทาง 8)

โจทย์ข้อที่ 5: การวิเคราะห์คุณสมบัติกราฟ (ดีกรี)

คำถาม: กำหนดกราฟไม่มีทิศทางที่มีจุดยอด 5 จุด (A, B, C, D, E) และเส้นเชื่อมดังนี้: {{A,B},{A,C},{B,C},{C,D},{D,E}}

จงหาดีกรี (degree) ของแต่ละจุดยอด (จำนวนเส้นเชื่อมที่ต่อกับจุดนั้น)

แนวคิด

  • นับจำนวนเส้นเชื่อมที่ต่อกับแต่ละจุดยอด

เฉลย

  • Degree(A): 2 (เชื่อมกับ B, C)
  • Degree(B): 2 (เชื่อมกับ A, C)
  • Degree(C): 3 (เชื่อมกับ A, B, D)
  • Degree(D): 2 (เชื่อมกับ C, E)
  • Degree(E): 1 (เชื่อมกับ D)

คำตอบ: Degree(A)=2, Degree(B)=2, Degree(C)=3, Degree(D)=2, Degree(E)=1

10.6.6 ตัวอย่างข้อสอบฝึกทำ

โจทย์ข้อที่ 6: การระบุส่วนประกอบและประเภทกราฟ

คำถาม: กำหนดกราฟดังรูป:

    A ----> B
    ^       |
    |       v
    D <---- C

จงระบุ:

  • ก. จุดยอดทั้งหมด
  • ข. เส้นเชื่อมทั้งหมด
  • ค. กราฟนี้เป็นกราฟมีทิศทางหรือไม่มีทิศทาง?

แนวคิด

  • จุดยอดคือวงกลมหรือจุดต่างๆ
  • เส้นเชื่อมคือเส้นที่มีลูกศร
  • ดูว่าเส้นเชื่อมมีลูกศรหรือไม่

เฉลย

ก. จุดยอดทั้งหมด: {A,B,C,D}

ข. เส้นเชื่อมทั้งหมด: {(A,B),(B,C),(C,D),(D,A)} (ใช้คู่อันดับแสดงเส้นเชื่อมมีทิศทาง)

ค. กราฟนี้เป็น กราฟมีทิศทาง

โจทย์ข้อที่ 7: การหาทางเดินและวงจร

คำถาม: กำหนดกราฟดังรูป:

    A ----> B
    ^       |
    |       v
    D <---- C ----> E

จงระบุ:

  • ก. ทางเดินอย่างง่ายจาก B ไป E
  • ข. วงจรทั้งหมดในกราฟนี้

แนวคิด

  • ทางเดินอย่างง่ายคือไม่มีจุดยอดซ้ำ
  • วงจรคือทางเดินที่กลับมาจุดเดิม

เฉลย

ก. ทางเดินอย่างง่ายจาก B ไป E: B → C → E

ข. วงจรทั้งหมด: A → B → C → D → A

โจทย์ข้อที่ 8: การตรวจสอบการเชื่อมโยง

คำถาม: กำหนดกราฟดังรูป:

    A ---- B ---- C
    
    D ---- E

กราฟนี้เป็นกราฟเชื่อมโยงหรือไม่? ถ้าไม่เชื่อมโยง มีส่วนประกอบที่เชื่อมโยงกี่ส่วน?

แนวคิด

  • กราฟเชื่อมโยงคือทุกจุดสามารถไปถึงกันได้
  • ส่วนประกอบที่เชื่อมโยงคือกลุ่มของจุดที่เชื่อมถึงกันภายในกลุ่มนั้น

เฉลย

กราฟนี้ ไม่เป็นกราฟเชื่อมโยง

มีส่วนประกอบที่เชื่อมโยง 2 ส่วน ได้แก่:

  • ส่วนที่ 1: {A,B,C}
  • ส่วนที่ 2: {D,E}

โจทย์ข้อที่ 9: การหาเส้นทางที่สั้นที่สุด (กราฟถ่วงน้ำหนัก)

คำถาม: จากแผนที่เมือง A, B, C, D ดังรูป (ตัวเลขบนเส้นคือระยะทาง) จงหาเส้นทางที่สั้นที่สุดจากเมือง A ไปเมือง D

     A ---2--- B
     |         |
     4         3
     |         |
     C ---1--- D

แนวคิด

  • ไล่เส้นทางที่เป็นไปได้ทั้งหมดจาก A ไป D และคำนวณระยะทางรวม
  • เลือกเส้นทางที่มีระยะทางน้อยที่สุด

เฉลย

เส้นทางที่เป็นไปได้จาก A ไป D:

  1. A → B → D: ระยะทาง: 2+3=5
  2. A → C → D: ระยะทาง: 4+1=5

คำตอบ: A → B → D (ระยะทาง 5) หรือ A → C → D (ระยะทาง 5)

โจทย์ข้อที่ 10: การวิเคราะห์คุณสมบัติกราฟ (ดีกรี)

คำถาม: กำหนดกราฟไม่มีทิศทางที่มีจุดยอด 4 จุด (P, Q, R, S) และเส้นเชื่อมดังนี้: {{P,Q},{P,R},{Q,R},{Q,S}}

จงหาดีกรี (degree) ของแต่ละจุดยอด

แนวคิด

  • นับจำนวนเส้นเชื่อมที่ต่อกับแต่ละจุดยอด

เฉลย

  • Degree(P): 2 (เชื่อมกับ Q, R)
  • Degree(Q): 3 (เชื่อมกับ P, R, S)
  • Degree(R): 2 (เชื่อมกับ P, Q)
  • Degree(S): 1 (เชื่อมกับ Q)

คำตอบ: Degree(P)=2, Degree(Q)=3, Degree(R)=2, Degree(S)=1
