บทที่ 9.8: การผสมผสานทั้งการเลือกทำ (if) และการวนทำซ้ำ (while)

การเรียนรู้การใช้โครงสร้างควบคุมแบบผสมผสานเพื่อสร้างโปรแกรมที่มีประสิทธิภาพ

เนื้อหาในบทเรียน

  • 9.8.1 แนวคิดการผสมผสาน if และ while
  • 9.8.2 ผังงานแสดงการผสมผสาน
  • 9.8.3 ความสำคัญของการผสมผสาน
  • 9.8.4 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ
  • 9.8.5 ตัวอย่างข้อสอบฝึกทำ

ในบทเรียนนี้ เราจะมาเรียนรู้การผสมผสานโครงสร้างควบคุมสองแบบเข้าด้วยกัน คือ การเลือกทำ (Conditional Execution) ด้วยคำสั่ง if และ การวนทำซ้ำ (Repetitive Execution) ด้วยลูป while การรวมกันของโครงสร้างทั้งสองนี้ช่วยให้โปรแกรมมีความสามารถในการตัดสินใจที่ซับซ้อนและทำงานซ้ำๆ ได้อย่างชาญฉลาด ซึ่งเป็นหัวใจสำคัญของการเขียนโปรแกรมที่ใช้งานได้จริง

9.8.1 แนวคิดการผสมผสาน if และ while

การผสมผสาน if และ while ช่วยให้เราสามารถ:

  • ตัดสินใจในแต่ละรอบของการวนซ้ำ: ทำสิ่งหนึ่งในรอบนี้ แต่ทำอีกสิ่งหนึ่งในรอบถัดไป ขึ้นอยู่กับเงื่อนไขที่เปลี่ยนแปลงไป
  • ควบคุมการวนซ้ำตามเงื่อนไขที่ซับซ้อน: ลูปอาจทำงานภายใต้เงื่อนไขหลัก แต่ภายในลูปมีการตัดสินใจย่อยๆ เพื่อปรับเปลี่ยนพฤติกรรม

ก. if ภายใน while (Nested if inside while)

นี่คือรูปแบบที่พบบ่อยที่สุด โดยลูป while จะทำซ้ำไปเรื่อยๆ และในแต่ละรอบของการวนซ้ำ โปรแกรมจะตรวจสอบเงื่อนไข if เพื่อตัดสินใจว่าจะทำคำสั่งใด

รูปแบบในภาษา Python

# กำหนดค่าเริ่มต้น
variable = initial_value
while condition_for_loop:
    # คำสั่งที่ทำในทุกรอบของลูป
    if condition_for_if:
        # คำสั่งที่จะทำเมื่อ condition_for_if เป็น True
    else:
        # คำสั่งที่จะทำเมื่อ condition_for_if เป็น False
    
    # คำสั่งอัปเดตค่าที่ทำให้ condition_for_loop เป็น False ในที่สุด
    variable = update_value

ตัวอย่าง: การนับเลขคู่/คี่ในแต่ละรอบ

count = 1
while count <= 5:
    if count % 2 == 0:  # ตรวจสอบว่าเป็นเลขคู่
        print(f"{count} เป็นเลขคู่")
    else:
        print(f"{count} เป็นเลขคี่")
    count += 1
print("จบการนับและตรวจสอบ")

คำอธิบาย:
ลูป while ทำงาน 5 รอบ (ตั้งแต่ count 1 ถึง 5) ในแต่ละรอบ:

  • ถ้า count เป็นเลขคู่ (เช่น 2, 4) จะพิมพ์ว่า "เป็นเลขคู่"
  • ถ้า count เป็นเลขคี่ (เช่น 1, 3, 5) จะพิมพ์ว่า "เป็นเลขคี่"

ข. while ภายใน if (Nested while inside if)

รูปแบบนี้หมายถึง ลูป while จะทำงาน ก็ต่อเมื่อเงื่อนไข if ภายนอกเป็นจริงเท่านั้น หากเงื่อนไข if เป็นเท็จ ลูป while จะไม่ถูกเรียกใช้เลย

รูปแบบในภาษา Python

if condition_for_if:
    # คำสั่งที่จะทำเมื่อ condition_for_if เป็น True
    
    # ลูป while ที่จะทำงานต่อเมื่อ if เป็น True
    variable = initial_value_for_loop
    while condition_for_loop:
        # คำสั่งภายในลูป
        variable = update_value_for_loop
else:
    # คำสั่งที่จะทำเมื่อ condition_for_if เป็น False

ตัวอย่าง: พิมพ์เลขคี่เท่านั้น

start_num = 7

if start_num % 2 != 0: # ถ้า start_num เป็นเลขคี่
    print(f"เริ่มต้นที่เลขคี่: {start_num}")
    current_num = start_num
    while current_num < 15:
        print(current_num)
        current_num += 2 # เพิ่มทีละ 2 เพื่อให้ยังคงเป็นเลขคี่
else:
    print(f"เริ่มต้นที่เลขคู่: {start_num} ไม่เข้าเงื่อนไข")

คำอธิบาย:

  • start_num (7) เป็นเลขคี่ (เงื่อนไข if เป็น True)
  • โปรแกรมเข้าบล็อก if และพิมพ์ "เริ่มต้นที่เลขคี่: 7"
  • จากนั้นลูป while จะทำงาน พิมพ์ 7, 9, 11, 13
  • ถ้า start_num เป็น 6 (เลขคู่) โปรแกรมจะพิมพ์ "เริ่มต้นที่เลขคู่: 6 ไม่เข้าเงื่อนไข" และลูป while จะไม่ทำงาน

9.8.2 ผังงานแสดงการผสมผสาน

ผังงาน (Flowchart) ช่วยให้เห็นภาพของการทำงานของโครงสร้างควบคุมแบบผสมผสานได้ชัดเจนขึ้น

องค์ประกอบสำคัญในผังงาน

  • รูปสี่เหลี่ยมผืนผ้า: แสดงคำสั่งหรือการดำเนินการ
  • รูปสี่เหลี่ยมข้าวหลามตัด: แสดงเงื่อนไข (condition) ที่ต้องตัดสินใจ
  • ลูกศร: แสดงทิศทางการทำงานของโปรแกรม
  • วงกลม: แสดงจุดเริ่มต้นและจุดสิ้นสุด

9.8.3 ความสำคัญของการผสมผสาน

  • ความยืดหยุ่นสูง: สามารถสร้างโปรแกรมที่ตอบสนองต่อข้อมูลและสถานการณ์ที่หลากหลาย
  • การจัดการข้อมูล: ใช้ในการประมวลผลข้อมูลในรายการ (list) หรือฐานข้อมูล โดยตรวจสอบเงื่อนไขสำหรับแต่ละรายการ
  • การสร้างเกม/แอปพลิเคชัน: ใช้ในการสร้างพฤติกรรมของตัวละครในเกม หรือการทำงานของปุ่มต่างๆ ที่ต้องมีการวนซ้ำและตัดสินใจ

9.8.4 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ

เอกสารนี้รวบรวมตัวอย่างโจทย์พื้นฐานสำหรับการทำความเข้าใจการผสมผสานโครงสร้างควบคุม if และ while เพื่อเตรียมความพร้อมสำหรับการสอบ สอวน. คอมพิวเตอร์ครับ

โจทย์ข้อที่ 1: if-else ภายใน while (นับและตรวจสอบ)

คำถาม: กำหนดรหัส Python

num = 1
while num <= 6:
    if num % 3 == 0:
        print(f"{num} หาร 3 ลงตัว")
    else:
        print(f"{num} หาร 3 ไม่ลงตัว")
    num += 1
print("สิ้นสุดการตรวจสอบ")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ติดตามค่า num ในแต่ละรอบของลูป while
  • ในแต่ละรอบ ตรวจสอบเงื่อนไข if num % 3 == 0 (หาร 3 ลงตัว)

โจทย์ข้อที่ 2: while ภายใน if (เงื่อนไขเริ่มต้น)

คำถาม: กำหนดรหัส Python

start_value = 10

if start_value > 5:
    print("เริ่มการนับจากค่าที่มากกว่า 5")
    i = start_value
    while i <= 15:
        print(i)
        i += 2
else:
    print("ค่าเริ่มต้นไม่เข้าเงื่อนไข")
print("จบโปรแกรม")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ตรวจสอบเงื่อนไข if start_value > 5 ก่อน
  • ถ้าเป็นจริง ลูป while จะทำงาน
  • ติดตามค่า i และเงื่อนไขของลูป while

เฉลย

  1. start_value = 10, เงื่อนไข if (10 > 5) เป็น True
  2. พิมพ์ "เริ่มการนับจากค่าที่มากกว่า 5"
  3. i = 10, ลูป while ทำงาน:
    • รอบ 1: i = 10 (≤ 15), พิมพ์ 10, i = 12
    • รอบ 2: i = 12 (≤ 15), พิมพ์ 12, i = 14
    • รอบ 3: i = 14 (≤ 15), พิมพ์ 14, i = 16
    • รอบ 4: i = 16 (> 15), ออกจากลูป
  4. พิมพ์ "จบโปรแกรม"

โจทย์ข้อที่ 5: การคำนวณสะสมในลูปที่มีเงื่อนไข

คำถาม: กำหนดรหัส Python

total_sum = 0
counter = 1
while counter <= 5:
    if counter % 2 != 0: # ถ้าเป็นเลขคี่
        total_sum += counter
    else: # ถ้าเป็นเลขคู่
        total_sum -= counter
    counter += 1
print(f"ผลรวมสุดท้าย: {total_sum}")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ติดตาม total_sum และ counter ในแต่ละรอบ
  • สังเกตว่า total_sum จะบวกเมื่อ counter เป็นคี่ และลบเมื่อ counter เป็นคู่

9.8.5 ตัวอย่างข้อสอบฝึกทำ

เอกสารนี้รวบรวมตัวอย่างข้อสอบสำหรับนักเรียนได้ฝึกทำในหัวข้อ "การผสมผสานทั้งการเลือกทำ (if) และการวนทำซ้ำ (while)" เพื่อเสริมสร้างความเข้าใจและเตรียมความพร้อมสำหรับการสอบ สอวน. คอมพิวเตอร์ครับ

โจทย์ข้อที่ 6: if ภายใน while (นับเฉพาะบางเงื่อนไข)

คำถาม: กำหนดรหัส Python

count = 0
num = 1
while num <= 10:
    if num % 2 == 0: # ถ้าเป็นเลขคู่
        count += 1
    num += 1
print(f"จำนวนเลขคู่: {count}")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • count จะเพิ่มขึ้นเมื่อ num เป็นเลขคู่เท่านั้น

เฉลย

ในช่วง 1 ถึง 10 มีเลขคู่: 2, 4, 6, 8, 10 (รวม 5 ตัว)

คำตอบ: จำนวนเลขคู่: 5

โจทย์ข้อที่ 7: while ภายใน if (เงื่อนไขซับซ้อน)

คำถาม: กำหนดรหัส Python

start_val = 15

if start_val > 10 and start_val % 3 == 0:
    print("เงื่อนไขเริ่มต้นตรงตามที่ต้องการ")
    i = start_val
    while i >= 5:
        print(i)
        i -= 5
else:
    print("เงื่อนไขเริ่มต้นไม่ตรง")
print("จบการทำงาน")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ตรวจสอบเงื่อนไข if ภายนอกทั้งหมดก่อน
  • ถ้าเป็นจริง ลูป while จะทำงาน

เฉลย

  1. start_val = 15
  2. เงื่อนไข: (15 > 10) และ (15 % 3 == 0) → True และ True = True
  3. พิมพ์ "เงื่อนไขเริ่มต้นตรงตามที่ต้องการ"
  4. i = 15, ลูป while ทำงาน:
    • รอบ 1: i = 15 (≥ 5), พิมพ์ 15, i = 10
    • รอบ 2: i = 10 (≥ 5), พิมพ์ 10, i = 5
    • รอบ 3: i = 5 (≥ 5), พิมพ์ 5, i = 0
    • รอบ 4: i = 0 (< 5), ออกจากลูป
  5. พิมพ์ "จบการทำงาน"

โจทย์ข้อที่ 8: if-elif-else ภายใน while (การจัดกลุ่ม)

คำถาม: กำหนดรหัส Python

x = 1
while x <= 7:
    if x < 3:
        print(f"{x}: กลุ่ม A")
    elif x < 6:
        print(f"{x}: กลุ่ม B")
    else:
        print(f"{x}: กลุ่ม C")
    x += 1
print("จัดกลุ่มเสร็จสิ้น")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ติดตามค่า x ในแต่ละรอบ
  • ในแต่ละรอบ ตรวจสอบเงื่อนไข if-elif-else ตามลำดับ

เฉลย

โจทย์ข้อที่ 9: การคำนวณผลคูณในลูปที่มีเงื่อนไข

คำถาม: กำหนดรหัส Python

product = 1
num = 1
while num <= 5:
    if num % 2 != 0: # ถ้าเป็นเลขคี่
        product *= num
    num += 1
print(f"ผลคูณสุดท้าย: {product}")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • product จะถูกคูณด้วย num เมื่อ num เป็นเลขคี่เท่านั้น

เฉลย

เลขคี่ในช่วง 1 ถึง 5: 1, 3, 5

ผลคูณ = 1 × 1 × 3 × 5 = 15

คำตอบ: ผลคูณสุดท้าย: 15

โจทย์ข้อที่ 10: if ซ้อน if ภายใน while (เงื่อนไขซับซ้อนและลูปไม่รู้จบ)

คำถาม: กำหนดรหัส Python

counter = 0
limit = 5
while counter < limit:
    if counter % 2 == 0:
        print(f"Even: {counter}")
        counter += 1
    else:
        print(f"Odd: {counter}")
        # ไม่มี counter += 1 ในบล็อก else
# print("End")

รหัสนี้จะทำงานอย่างไร? (ลูปไม่รู้จบหรือไม่) ถ้าไม่รู้จบเพราะอะไร?

แนวคิด

  • ติดตามค่า counter อย่างละเอียด
  • สังเกตว่า counter จะเพิ่มขึ้นเมื่อ counter เป็นเลขคู่เท่านั้น
  • ถ้า counter เป็นเลขคี่ จะไม่มีการอัปเดตค่า counter ทำให้ติดอยู่ในลูป

เฉลย

รหัสนี้จะทำงานเป็น ลูปไม่รู้จบ (Infinite Loop)

เหตุผล:

  1. counter เริ่มที่ 0 (คู่) → พิมพ์ "Even: 0", counter เป็น 1
  2. counter เป็น 1 (คี่) → พิมพ์ "Odd: 1"
  3. ในบล็อก else (เมื่อ counter เป็นคี่) ไม่มีคำสั่ง counter += 1
  4. ดังนั้น counter จะติดอยู่ที่ค่า 1 ตลอดไป (1 < 5 เป็น True เสมอ) ทำให้ลูปทำงานซ้ำๆ ไม่มีที่สิ้นสุด

คำตอบ: ลูปไม่รู้จบ, เพราะเมื่อ counter เป็นเลขคี่ จะไม่มีการอัปเดตค่า counter ทำให้เงื่อนไข counter < limit เป็นจริงตลอดไป
