บทที่ 10.2: การหาผลลัพธ์เมื่อกำหนด Input ตามวิธีการที่กำหนด

การฝึกฝนทักษะการคิดเชิงวิเคราะห์ในการหาผลลัพธ์ของอัลกอริทึมเมื่อมีข้อมูลนำเข้าที่กำหนด

เนื้อหาในบทเรียน

  • 10.2.1 การหาผลลัพธ์จากข้อมูลนำเข้า (Finding Output from Input)
  • 10.2.2 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ
  • 10.2.3 ตัวอย่างข้อสอบฝึกทำ

ในบทเรียนนี้ เราจะฝึกฝนทักษะสำคัญในการคิดเชิงวิเคราะห์ นั่นคือ การหาผลลัพธ์ของขั้นตอนวิธี (Algorithm Output) เมื่อมีการกำหนดข้อมูลนำเข้า (Input) ให้ การทำความเข้าใจและตีความขั้นตอนวิธีที่นำเสนอในรูปแบบของรหัสเทียม (Pseudocode) หรือผังงาน (Flowchart) และการติดตามการทำงานของมันอย่างเป็นระบบ เป็นหัวใจสำคัญของการเขียนโปรแกรมและการแก้ปัญหาในวิทยาการคอมพิวเตอร์

10.2.1 การหาผลลัพธ์จากข้อมูลนำเข้า (Finding Output from Input)

การหาผลลัพธ์เมื่อกำหนด Input ตามวิธีการที่กำหนด คือกระบวนการที่เราจำลองการทำงานของโปรแกรมหรืออัลกอริทึมทีละขั้นตอน โดยใช้ข้อมูลนำเข้าที่ระบุไว้ เพื่อติดตามการเปลี่ยนแปลงของตัวแปรและการทำงานของคำสั่งต่างๆ จนกว่าจะได้ผลลัพธ์สุดท้าย

หลักการสำคัญ:

1. การแกะรอย (Tracing):

เป็นเทคนิคหลักที่ใช้ในขั้นตอนนี้ โดยการสร้างตารางติดตามตัวแปร (Trace Table) เพื่อบันทึกค่าของตัวแปรทุกตัวในแต่ละบรรทัดหรือแต่ละรอบของการทำงาน

2. การประมวลผลตามลำดับ:

คำสั่งจะถูกประมวลผลจากบนลงล่าง และจากซ้ายไปขวา (ในบรรทัดเดียวกัน) เสมอ

3. การตัดสินใจ:

เมื่อเจอเงื่อนไข (เช่น IF, ELSE IF) ให้ประเมินค่าความจริงของเงื่อนไขนั้น (True หรือ False) แล้วเลือกเส้นทางที่ถูกต้อง

4. การวนซ้ำ:

เมื่อเจอลูป (WHILE) ให้ทำคำสั่งในบล็อกของลูปซ้ำๆ ตราบเท่าที่เงื่อนไขของลูปยังเป็นจริง และอย่าลืมอัปเดตค่าตัวแปรที่ใช้ในเงื่อนไขเพื่อป้องกันลูปไม่รู้จบ

10.2.2 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ

ในส่วนนี้ เราจะมาฝึกทำความเข้าใจและหาผลลัพธ์จากขั้นตอนวิธีที่กำหนดให้

โจทย์ข้อที่ 1: การหาผลลัพธ์จากรหัสเทียม (ลำดับขั้นตอน)

คำถาม: กำหนดรหัสเทียมต่อไปนี้

START
  INPUT num1
  INPUT num2
  SET sum TO num1 + num2
  SET product TO num1 * num2
  PRINT sum
  PRINT product
END

ถ้าผู้ใช้ป้อน num1 = 5 และ num2 = 3 จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • สร้างตารางติดตามตัวแปรเพื่อบันทึกค่า num1, num2, sum, product
  • ไล่คำสั่งทีละบรรทัดตามลำดับ

โจทย์ข้อที่ 3: การหาผลลัพธ์จากรหัสเทียม (การวนซ้ำ WHILE)

คำถาม: กำหนดรหัสเทียมต่อไปนี้

START
  SET i TO 1
  SET total TO 0
  WHILE i <= 3 DO
    total = total + (i * 10)
    i = i + 1
  END WHILE
  PRINT total
END

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • สร้างตารางติดตามตัวแปร โดยเพิ่มคอลัมน์ "รอบ" เพื่อติดตามการวนซ้ำ
  • ในแต่ละรอบ ให้ตรวจสอบเงื่อนไข WHILE ก่อนเสมอ

  10. num = num + 1: num กลายเป็น 3
  11. num <= 5?: (3 ≤ 5) เป็น True
  12. num % 2 == 0?: (3 % 2 == 0) เป็น False
  13. sum_odd = sum_odd + num: sum_odd กลายเป็น 1 + 3 = 4
  14. num = num + 1: num กลายเป็น 4
  15. num <= 5?: (4 ≤ 5) เป็น True
  16. num % 2 == 0?: (4 % 2 == 0) เป็น True
  17. sum_even = sum_even + num: sum_even กลายเป็น 2 + 4 = 6
  18. num = num + 1: num กลายเป็น 5
  19. num <= 5?: (5 ≤ 5) เป็น True
  20. num % 2 == 0?: (5 % 2 == 0) เป็น False
  21. sum_odd = sum_odd + num: sum_odd กลายเป็น 4 + 5 = 9

โจทย์ข้อที่ 5: การหาผลลัพธ์จากรหัสเทียม (เงื่อนไขซับซ้อน)

คำถาม: กำหนดรหัสเทียมต่อไปนี้

START
  INPUT age
  INPUT has_license
  INPUT has_car
  IF age >= 18 AND has_license == TRUE THEN
    IF has_car == TRUE THEN
      PRINT "คุณสามารถขับรถของตัวเองได้"
    ELSE
      PRINT "คุณสามารถขับรถได้ แต่ไม่มีรถ"
    END IF
  ELSE IF age >= 18 AND has_license == FALSE THEN
    PRINT "คุณมีอายุพอ แต่ยังไม่มีใบขับขี่"
  ELSE
    PRINT "คุณยังเด็กเกินไป"
  END IF
END

ถ้าผู้ใช้ป้อน age = 25, has_license = TRUE, และ has_car = FALSE จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ประเมินเงื่อนไข AND ก่อน
  • ตรวจสอบเงื่อนไข IF และ ELSE IF ตามลำดับ
  • หากเข้าบล็อก IF หลัก ให้ตรวจสอบเงื่อนไข IF ที่ซ้อนอยู่ภายในอีกครั้ง

10.2.3 ตัวอย่างข้อสอบฝึกทำ

โจทย์ข้อที่ 6: การหาผลลัพธ์จากรหัสเทียม (การคำนวณสะสมในลูป)

คำถาม: กำหนดรหัสเทียมต่อไปนี้

START
  SET i TO 1
  SET total_sum TO 0
  WHILE i <= 5 DO
    total_sum = total_sum + (i * 2)
    i = i + 1
  END WHILE
  PRINT total_sum
END

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ติดตาม i และ total_sum ในแต่ละรอบของลูป while
  • total_sum จะเก็บผลรวมสะสม

เฉลย

รอบ 1: total_sum = 0 + (1 × 2) = 2, i = 2

รอบ 2: total_sum = 2 + (2 × 2) = 6, i = 3

รอบ 3: total_sum = 6 + (3 × 2) = 12, i = 4

รอบ 4: total_sum = 12 + (4 × 2) = 20, i = 5

รอบ 5: total_sum = 20 + (5 × 2) = 30, i = 6

รอบ 6: i = 6 (> 5), ออกจากลูป

ผลลัพธ์คือ 30

โจทย์ข้อที่ 8: การหาผลลัพธ์จากรหัสเทียม (ลูปไม่รู้จบ)

  END WHILE
  PRINT "จบ"

รหัสนี้จะทำงานอย่างไร? (ลูปไม่รู้จบหรือไม่) ถ้าไม่รู้จบเพราะอะไร?

แนวคิด

  • ตรวจสอบว่าตัวแปรที่ใช้ในเงื่อนไขมีการเปลี่ยนแปลงที่ทำให้เงื่อนไขเป็นเท็จได้หรือไม่

โจทย์ข้อที่ 10: การหาผลลัพธ์จากรหัสเทียม (การสลับค่าในลูป)

คำถาม: กำหนดรหัสเทียมต่อไปนี้

  SET B TO 0
  SET count TO 0

    A = B

  • ติดตามค่า A, B, temp, count ในแต่ละรอบ
  • สังเกตว่านี่คือการคำนวณลำดับที่คล้ายฟิโบนักชีแต่มีการสลับค่า
