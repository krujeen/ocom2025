บทที่ 9.1: โครงสร้างพื้นฐานของโปรแกรม (ลำดับขั้นตอน)

การทำความเข้าใจพื้นฐานการทำงานแบบลำดับขั้นตอนในการเขียนโปรแกรม

เนื้อหาในบทเรียน

  • 9.1.1 การทำงานแบบลำดับขั้นตอน (Sequential Execution)
  • 9.1.2 การแทนโครงสร้างพื้นฐานของโปรแกรม
  • 9.1.3 ความสำคัญของการทำงานแบบลำดับขั้นตอน
  • 9.1.4 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ
  • 9.1.5 ตัวอย่างข้อสอบฝึกทำ

ในบทเรียนนี้ เราจะมาทำความเข้าใจเกี่ยวกับ "โครงสร้างพื้นฐานของโปรแกรม" โดยเฉพาะแนวคิดของ "ลำดับขั้นตอน" หรือการทำงานแบบเรียงลำดับ ซึ่งเป็นหลักการพื้นฐานที่สุดในการเขียนโปรแกรมคอมพิวเตอร์ การเข้าใจหลักการนี้เป็นสิ่งจำเป็นอย่างยิ่งสำหรับการสร้างโปรแกรมที่ทำงานได้อย่างถูกต้องและคาดการณ์ผลลัพธ์ได้ครับ

9.1.1 การทำงานแบบลำดับขั้นตอน (Sequential Execution)

การทำงานแบบลำดับขั้นตอน (Sequential Execution) คือ รูปแบบการทำงานของโปรแกรมที่คำสั่งต่างๆ จะถูกประมวลผล ทีละคำสั่งตามลำดับที่เขียนไว้จากบนลงล่าง และจากซ้ายไปขวา (สำหรับบรรทัดเดียวกัน) จนกว่าจะสิ้นสุดการทำงานของโปรแกรม

แนวคิดหลัก

โปรแกรมจะทำตาม "ขั้นตอนที่ 1, แล้วทำขั้นตอนที่ 2, แล้วทำขั้นตอนที่ 3, ..." โดยไม่มีการข้ามคำสั่งหรือย้อนกลับไปทำซ้ำ (ในโครงสร้างพื้นฐานนี้)

ตัวอย่างเปรียบเทียบ: ลองนึกถึงการทำอาหารตามสูตรอาหาร โปรแกรมจะทำตามคำสั่งทีละข้อตามลำดับที่ระบุไว้ หากข้ามขั้นตอนใดไป หรือทำผิดลำดับ ผลลัพธ์ที่ได้อาจจะไม่ถูกต้อง

องค์ประกอบพื้นฐานของการทำงานแบบลำดับขั้นตอน:

  • การรับข้อมูลนำเข้า (Input): การนำข้อมูลจากภายนอกเข้าสู่โปรแกรม (เช่น รับค่าจากผู้ใช้, อ่านจากไฟล์)
  • การประมวลผล (Process): การคำนวณ, การเปรียบเทียบ, การจัดการข้อมูลภายในโปรแกรม
  • การแสดงผล (Output): การแสดงผลลัพธ์หรือข้อมูลออกสู่ภายนอก (เช่น แสดงบนหน้าจอ, เขียนลงไฟล์)

9.1.2 การแทนโครงสร้างพื้นฐานของโปรแกรม

เราสามารถแสดงการทำงานแบบลำดับขั้นตอนได้หลายวิธี เช่น:

ก. รหัสเทียม (Pseudocode) และ ภาษา Python

รหัสเทียม (Pseudocode) คือ การอธิบายขั้นตอนการทำงานของโปรแกรมหรืออัลกอริทึมด้วยภาษาที่คล้ายภาษาคอมพิวเตอร์แต่ไม่ต้องมีไวยากรณ์ที่เคร่งครัด ใช้คำพูดที่เข้าใจง่าย เพื่อให้มนุษย์เข้าใจได้โดยไม่ต้องกังวลถึงรายละเอียดทางเทคนิคของภาษาโปรแกรมใดๆ

คำสั่งพื้นฐานในรหัสเทียมและเทียบกับภาษา Python:

คำสั่งในรหัสเทียม ความหมาย คำสั่งในภาษา Python (ตัวอย่าง)
START / BEGIN จุดเริ่มต้นของโปรแกรม (ไม่จำเป็นต้องมีคำสั่งเฉพาะ, โปรแกรมเริ่มจากบรรทัดแรก)
INPUT <ตัวแปร> รับค่าเข้าสู่ตัวแปร variable = input("Enter value: ") (รับเป็นข้อความ)
SET <ตัวแปร> TO <ค่า/นิพจน์> หรือ <ตัวแปร> = <ค่า/นิพจน์> กำหนดค่าให้ตัวแปร variable = 10 หรือ result = a + b
CALCULATE <นิพจน์> ประมวลผล result = num1 * num2 (มักจะรวมกับการกำหนดค่า)
PRINT <ข้อความ/ตัวแปร> / DISPLAY <ข้อความ/ตัวแปร> แสดงผลลัพธ์ print("Hello World") หรือ print(variable)
END จุดสิ้นสุดของโปรแกรม (ไม่จำเป็นต้องมีคำสั่งเฉพาะ, โปรแกรมสิ้นสุดเมื่อไม่มีคำสั่งให้ทำ)

ตัวอย่าง

ตัวอย่างรหัสเทียม (การบวกเลข 2 จำนวน):

START
  INPUT number1
  INPUT number2
  SET sum TO number1 + number2
  PRINT sum
END

เทียบเท่าในภาษา Python:

# รับค่าจากผู้ใช้ (input() จะรับเป็นข้อความ จึงต้องแปลงเป็นตัวเลขด้วย int())
number1 = int(input("ป้อนตัวเลขแรก: "))
number2 = int(input("ป้อนตัวเลขที่สอง: "))

# คำนวณผลรวม
sum_result = number1 + number2

# แสดงผลลัพธ์
print("ผลรวมคือ:", sum_result)

ข. ผังงาน (Flowchart)

ผังงาน (Flowchart) คือ การแสดงขั้นตอนการทำงานของโปรแกรมหรืออัลกอริทึมด้วยสัญลักษณ์ภาพมาตรฐาน ซึ่งช่วยให้เห็นภาพรวมของลำดับการทำงานได้อย่างชัดเจน

สัญลักษณ์พื้นฐานในผังงาน (สำหรับลำดับขั้นตอน):

  • วงรี / สี่เหลี่ยมโค้งมน (Terminal): จุดเริ่มต้น (Start) หรือจุดสิ้นสุด (End) ของโปรแกรม
  • สี่เหลี่ยมด้านขนาน (Input/Output): การรับข้อมูลนำเข้า (Input) หรือการแสดงผลลัพธ์ (Output)
  • สี่เหลี่ยมผืนผ้า (Process): การประมวลผล, การคำนวณ, การกำหนดค่า
  • ลูกศร (Flowline): แสดงทิศทางของลำดับการทำงาน

ตัวอย่างผังงาน

ตัวอย่างผังงาน (การบวกเลข 2 จำนวน):

[Start] → [Input number1] → [Input number2] → [sum = number1 + number2] → [Print sum] → [End]

9.1.3 ความสำคัญของการทำงานแบบลำดับขั้นตอน

  • พื้นฐาน: เป็นโครงสร้างหลักของโปรแกรมทุกชนิด อัลกอริทึมส่วนใหญ่เริ่มต้นจากการทำงานแบบลำดับ
  • คาดการณ์ผลลัพธ์ได้: การทำตามลำดับช่วยให้โปรแกรมทำงานอย่างเป็นระบบ ทำให้สามารถคาดเดาผลลัพธ์ได้ง่าย
  • ง่ายต่อการดีบัก: หากเกิดข้อผิดพลาด สามารถไล่ตามลำดับคำสั่งเพื่อหาจุดที่ผิดพลาดได้ง่าย
  • สร้างความเข้าใจ: เป็นรากฐานสำหรับการเรียนรู้โครงสร้างโปรแกรมที่ซับซ้อนขึ้น เช่น การเลือกทำ (เงื่อนไข) และการทำซ้ำ (ลูป)

9.1.4 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ

เอกสารนี้รวบรวมตัวอย่างโจทย์พื้นฐานสำหรับการเขียนโปรแกรมและการติดตามการทำงานในโครงสร้างลำดับขั้นตอน เพื่อเสริมสร้างความเข้าใจในหลักการพื้นฐานและเตรียมความพร้อมสำหรับการสอบ สอวน. คอมพิวเตอร์ครับ

โจทย์ข้อที่ 1: การเขียนรหัส Python และผังงาน (บวกเลข)

คำถาม: จงเขียนรหัส Python และผังงานแสดงขั้นตอนการทำงานของโปรแกรมที่รับตัวเลขจำนวนเต็ม 2 จำนวน แล้วคำนวณผลบวกของตัวเลขทั้งสอง และแสดงผลลัพธ์ออกทางหน้าจอ

แนวคิด

  • ระบุขั้นตอน: เริ่มต้น, รับข้อมูล, ประมวลผล, แสดงผล, สิ้นสุด
  • แปลงแต่ละขั้นตอนเป็นรหัส Python
  • แปลงแต่ละขั้นตอนเป็นสัญลักษณ์ผังงาน

เฉลย

รหัส Python:

# รับตัวเลขสองจำนวนจากผู้ใช้
num1 = int(input("ป้อนตัวเลขแรก: "))
num2 = int(input("ป้อนตัวเลขที่สอง: "))

# คำนวณผลบวก
sum_result = num1 + num2

# แสดงผลลัพธ์
print("ผลรวมคือ:", sum_result)

ผังงาน:
[Start] → [Input num1] → [Input num2] → [sum_result = num1 + num2] → [Print sum_result] → [End]

คำตอบ: ดูรหัส Python และผังงานข้างต้น

โจทย์ข้อที่ 2: การติดตามการทำงานของรหัส Python (Tracing Code)

คำถาม: กำหนดรหัส Python ต่อไปนี้

a = 10
b = 5
c = a * b
a = a + c
print(a)

ถ้าเริ่มต้น a มีค่า 10 และ b มีค่า 5 จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • สร้างตารางเพื่อติดตามค่าของตัวแปรในแต่ละบรรทัด
  • ไล่คำสั่งทีละบรรทัดและอัปเดตค่าในตาราง

เฉลย

บรรทัด คำสั่ง a b c ผลลัพธ์ที่พิมพ์
1 a = 10 10 - -
2 b = 5 10 5 -
3 c = a * b 10 5 50
4 a = a + c 60 5 50
5 print(a) 60 5 50 60

คำตอบ: 60

โจทย์ข้อที่ 3: การวิเคราะห์ผลลัพธ์จากผังงาน

คำถาม: กำหนดผังงานต่อไปนี้

[Start] → [Input X] → [Y = X + 5] → [Print Y] → [End]

ถ้าผู้ใช้ป้อนค่า X=15 จงหาผลลัพธ์ที่แสดงบนหน้าจอ

แนวคิด

  • ไล่ตามทิศทางของลูกศรในผังงาน
  • ดำเนินการตามคำสั่งในแต่ละสัญลักษณ์

เฉลย

  1. Start: โปรแกรมเริ่มต้น
  2. Input X: รับค่า X จากผู้ใช้ ซึ่งคือ 15
  3. Y = X + 5: คำนวณค่า Y โดยนำค่า X มาบวก 5
    Y = 15 + 5 = 20
  4. Print Y: แสดงค่า Y ออกทางหน้าจอ ซึ่งคือ 20
  5. End: โปรแกรมสิ้นสุด

คำตอบ: 20

โจทย์ข้อที่ 4: การคำนวณพื้นที่ (ผสมผสาน)

คำถาม: จงเขียนรหัส Python และผังงานแสดงขั้นตอนการคำนวณพื้นที่ของรูปสี่เหลี่ยมผืนผ้า โดยรับค่าความกว้างและความยาวจากผู้ใช้ และแสดงผลลัพธ์พื้นที่

แนวคิด

  • ระบุข้อมูลที่ต้องการ (ความกว้าง, ความยาว)
  • ระบุการประมวลผล (คำนวณพื้นที่ = กว้าง × ยาว)
  • ระบุการแสดงผล (พื้นที่)

เฉลย

รหัส Python:

# รับค่าความกว้างและความยาวจากผู้ใช้
width = float(input("ป้อนความกว้าง: "))
length = float(input("ป้อนความยาว: "))

# คำนวณพื้นที่
area = width * length

# แสดงผลลัพธ์
print("พื้นที่ของรูปสี่เหลี่ยมผืนผ้าคือ:", area)

ผังงาน:
[Start] → [Input width] → [Input length] → [area = width × length] → [Print area] → [End]

คำตอบ: ดูรหัส Python และผังงานข้างต้น

โจทย์ข้อที่ 5: การทำงานพื้นฐานของตัวแปร (การสลับค่า)

คำถาม: กำหนดรหัส Python ต่อไปนี้

num1 = 5
num2 = 10
num1 = num1 + num2
num2 = num1 - num2
num1 = num1 - num2
print(num1)
print(num2)

จงหาค่าของ num1 และ num2 ที่พิมพ์ออกมา

แนวคิด

  • ติดตามค่าของตัวแปร num1 และ num2 อย่างรอบคอบในแต่ละบรรทัด
  • สังเกตว่าการดำเนินการเหล่านี้เป็นการสลับค่าตัวแปรโดยไม่ใช้ตัวแปรชั่วคราว

เฉลย

บรรทัด คำสั่ง num1 num2 ผลลัพธ์ที่พิมพ์
1num1 = 55-
2num2 = 10510
3num1 = num1 + num21510
4num2 = num1 - num2155
5num1 = num1 - num2105
6print(num1)10510
7print(num2)1055

คำตอบ: num1 = 10, num2 = 5

9.1.5 ตัวอย่างข้อสอบฝึกทำ

เอกสารนี้รวบรวมตัวอย่างข้อสอบสำหรับนักเรียนได้ฝึกทำในหัวข้อ "โครงสร้างพื้นฐานของโปรแกรม (ลำดับขั้นตอน)" เพื่อเสริมสร้างความเข้าใจและเตรียมความพร้อมสำหรับการสอบ สอวน. คอมพิวเตอร์ครับ

โจทย์ข้อที่ 6: การติดตามการทำงานของรหัส Python (การคำนวณซับซ้อนขึ้น)

คำถาม: กำหนดรหัส Python ต่อไปนี้

x = 3
y = 4
z = 5
x = x + y
y = y * z
z = x - y
print(z)

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • สร้างตารางเพื่อติดตามค่าของตัวแปร x, y, z ในแต่ละบรรทัด
  • ไล่คำสั่งทีละบรรทัดและอัปเดตค่าในตาราง

เฉลย

บรรทัด คำสั่ง x y z ผลลัพธ์ที่พิมพ์
1x = 33--
2y = 434-
3z = 5345
4x = x + y745
5y = y * z7205
6z = x - y720-13
7print(z)720-13-13

คำตอบ: -13

โจทย์ข้อที่ 7: การวิเคราะห์ผลลัพธ์จากผังงาน (การคำนวณหลายขั้นตอน)

คำถาม: กำหนดผังงานต่อไปนี้

[Start] → [Input A] → [B = A * 2] → [C = B + 10] → [Print C] → [End]

ถ้าผู้ใช้ป้อนค่า A=8 จงหาผลลัพธ์ที่แสดงบนหน้าจอ

แนวคิด

  • ไล่ตามทิศทางของลูกศรในผังงาน
  • ดำเนินการตามคำสั่งในแต่ละสัญลักษณ์

เฉลย

  1. Start: โปรแกรมเริ่มต้น
  2. Input A: รับค่า A จากผู้ใช้ ซึ่งคือ 8
  3. B = A * 2: คำนวณค่า B โดยนำค่า A มาคูณ 2
    B = 8 × 2 = 16
  4. C = B + 10: คำนวณค่า C โดยนำค่า B มาบวก 10
    C = 16 + 10 = 26
  5. Print C: แสดงค่า C ออกทางหน้าจอ ซึ่งคือ 26
  6. End: โปรแกรมสิ้นสุด

คำตอบ: 26

โจทย์ข้อที่ 8: การเขียนรหัส Python (คำนวณพื้นที่วงกลม)

คำถาม: จงเขียนรหัส Python แสดงขั้นตอนการคำนวณพื้นที่ของรูปวงกลม โดยรับค่ารัศมีจากผู้ใช้ และแสดงผลลัพธ์พื้นที่ (ใช้ค่า π = 3.14)

แนวคิด

  • ระบุข้อมูลที่ต้องการ (รัศมี)
  • ระบุการประมวลผล (คำนวณพื้นที่ = π × รัศมี²)
  • ระบุการแสดงผล (พื้นที่)

เฉลย

# รับค่ารัศมีจากผู้ใช้
radius = float(input("ป้อนรัศมีวงกลม: "))

# กำหนดค่า Pi
PI = 3.14

# คำนวณพื้นที่วงกลม
area = PI * radius * radius

# แสดงผลลัพธ์
print("พื้นที่ของวงกลมคือ:", area)

คำตอบ: ดูรหัส Python ข้างต้น

โจทย์ข้อที่ 9: การติดตามการทำงานของรหัส Python (การคำนวณเศษส่วน)
