บทที่ 9.4: การเขียนนิพจน์เพื่อการเปรียบเทียบ

การเรียนรู้การใช้ตัวดำเนินการเปรียบเทียบและการสร้างเงื่อนไขในโปรแกรม

ในบทเรียนนี้ เราจะมาเรียนรู้เกี่ยวกับ การเขียนนิพจน์เพื่อการเปรียบเทียบ (Comparison Expressions) ในภาษา Python ซึ่งเป็นสิ่งสำคัญสำหรับการสร้างเงื่อนไข (conditions) ในโปรแกรมคอมพิวเตอร์ การเข้าใจตัวดำเนินการเปรียบเทียบจะช่วยให้โปรแกรมของคุณสามารถตัดสินใจและทำงานตามเงื่อนไขที่กำหนดได้อย่างถูกต้อง

9.4.1 นิพจน์เพื่อการเปรียบเทียบ (Comparison Expressions)

นิพจน์เพื่อการเปรียบเทียบ (Comparison Expression) คือ การเปรียบเทียบค่าสองค่า (ตัวเลข, ตัวแปร, หรือนิพจน์) โดยใช้ตัวดำเนินการเปรียบเทียบ ผลลัพธ์ของการเปรียบเทียบจะเป็นค่าความจริงแบบ บูลีน (Boolean) ซึ่งมีเพียงสองค่าเท่านั้นคือ True (จริง) หรือ False (เท็จ)

ตัวอย่าง

  • 5 > 3 จะให้ผลลัพธ์เป็น True
  • x == y จะให้ผลลัพธ์เป็น True ถ้า x มีค่าเท่ากับ y มิฉะนั้นจะเป็น False

9.4.2 ตัวดำเนินการเปรียบเทียบใน Python (Comparison Operators)

Python มีตัวดำเนินการพื้นฐานสำหรับการเปรียบเทียบดังนี้:

ตัวดำเนินการ ความหมาย ตัวอย่าง Python ผลลัพธ์
== เท่ากับ x == 5 True (ถ้า x คือ 5), False (ถ้า x ไม่ใช่ 5)
!= ไม่เท่ากับ y != 10 True (ถ้า y ไม่ใช่ 10), False (ถ้า y คือ 10)
< น้อยกว่า age < 18 True (ถ้า age น้อยกว่า 18)
<= น้อยกว่าหรือเท่ากับ score <= 100 True (ถ้า score น้อยกว่าหรือเท่ากับ 100)
> มากกว่า temp > 25 True (ถ้า temp มากกว่า 25)
>= มากกว่าหรือเท่ากับ level >= 5 True (ถ้า level มากกว่าหรือเท่ากับ 5)

ข้อควรระวัง

  • == (เท่ากับ) แตกต่างจาก = (กำหนดค่าให้ตัวแปร)
  • การเปรียบเทียบข้อความ (String) จะเปรียบเทียบตามลำดับตัวอักษรในรหัส ASCII/Unicode (เช่น "apple" < "banana" ให้ True)

9.4.3 ลำดับความสำคัญของตัวดำเนินการ (Operator Precedence)

ตัวดำเนินการเปรียบเทียบมีความสำคัญต่ำกว่าตัวดำเนินการทางคณิตศาสตร์ แต่สูงกว่าตัวดำเนินการทางตรรกศาสตร์ (เช่น and, or)

ลำดับความสำคัญ (จากสูงไปต่ำ)

  1. ตัวดำเนินการทางคณิตศาสตร์ (+, -, *, /, **, //, %) จะถูกประมวลผลก่อน
  2. ตัวดำเนินการเปรียบเทียบ (==, !=, <, <=, >, >=) จะถูกประมวลผลถัดมา
  3. ตัวดำเนินการทางตรรกศาสตร์ (not, and, or) จะถูกประมวลผลสุดท้าย

ตัวอย่าง

  • 5 + 3 > 10 จะคำนวณ 5 + 3 ก่อน ได้ 8 แล้วเปรียบเทียบ 8 > 10 ได้ False
  • (x * 2) == 10 จะคำนวณ x * 2 ก่อน แล้วค่อยเปรียบเทียบ

9.4.4 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ

เอกสารนี้รวบรวมตัวอย่างโจทย์พื้นฐานสำหรับการทำความเข้าใจการเปรียบเทียบนิพจน์และการประเมินค่าความจริง เพื่อเตรียมความพร้อมสำหรับการสอบ สอวน. คอมพิวเตอร์ครับ

โจทย์ข้อที่ 1: การเปรียบเทียบพื้นฐาน

คำถาม: จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

7 > 5

แนวคิด

  • เปรียบเทียบค่าตรงๆ

เฉลย

7 มากกว่า 5 ดังนั้นผลลัพธ์คือ True

คำตอบ: True

โจทย์ข้อที่ 2: การเปรียบเทียบความเท่ากัน

คำถาม: จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

(10 + 2) == 12

แนวคิด

  • วงเล็บก่อน
  • เปรียบเทียบความเท่ากัน

เฉลย

  1. (10 + 2) คำนวณก่อน ได้ 12
  2. นิพจน์กลายเป็น 12 == 12
  3. ได้ผลลัพธ์ True

คำตอบ: True

โจทย์ข้อที่ 3: การเปรียบเทียบความไม่เท่ากัน

คำถาม: จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

(20 / 4) != 5

แนวคิด

  • หารก่อน (ระวังผลลัพธ์เป็น float)
  • เปรียบเทียบความไม่เท่ากัน

เฉลย

  1. (20 / 4) คำนวณก่อน ได้ 5.0
  2. นิพจน์กลายเป็น 5.0 != 5
  3. 5.0 เท่ากับ 5 (ในเชิงค่า) ดังนั้นผลลัพธ์คือ False

คำตอบ: False

โจทย์ข้อที่ 4: การเปรียบเทียบที่มีตัวแปร

คำถาม: กำหนดให้ x = 15 และ y = 10 จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

x - y >= 5

แนวคิด

  • แทนค่าตัวแปร
  • ลบก่อน
  • เปรียบเทียบ

เฉลย

  1. แทนค่า: 15 - 10 >= 5
  2. 15 - 10 คำนวณก่อน ได้ 5
  3. นิพจน์กลายเป็น 5 >= 5
  4. ได้ผลลัพธ์ True

คำตอบ: True

โจทย์ข้อที่ 5: การผสมผสานตัวดำเนินการหลายชนิด

คำถาม: จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

(3 ** 2) < (2 * 5)

แนวคิด

  • วงเล็บก่อน
  • ยกกำลัง
  • คูณ
  • เปรียบเทียบ

เฉลย

  1. (3 ** 2) คำนวณก่อน ได้ 9
  2. (2 * 5) คำนวณก่อน ได้ 10
  3. นิพจน์กลายเป็น 9 < 10
  4. ได้ผลลัพธ์ True

คำตอบ: True

9.4.5 ตัวอย่างข้อสอบฝึกทำ

เอกสารนี้รวบรวมตัวอย่างข้อสอบสำหรับนักเรียนได้ฝึกทำในหัวข้อ "การเขียนนิพจน์เพื่อการเปรียบเทียบ" เพื่อเสริมสร้างความเข้าใจและเตรียมความพร้อมสำหรับการสอบ สอวน. คอมพิวเตอร์ครับ

โจทย์ข้อที่ 6: การเปรียบเทียบความเท่ากัน

คำถาม: จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

(10 * 3) == 30

แนวคิด

  • คูณก่อน
  • เปรียบเทียบความเท่ากัน

เฉลย

  1. (10 * 3) คำนวณก่อน ได้ 30
  2. นิพจน์กลายเป็น 30 == 30
  3. ได้ผลลัพธ์ True

คำตอบ: True

โจทย์ข้อที่ 7: การเปรียบเทียบความไม่เท่ากัน

คำถาม: จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

(15 % 4) != 3

แนวคิด

  • หารเอาเศษก่อน
  • เปรียบเทียบความไม่เท่ากัน

เฉลย

  1. (15 % 4) คำนวณก่อน ได้ 3
  2. นิพจน์กลายเป็น 3 != 3
  3. ได้ผลลัพธ์ False

คำตอบ: False

โจทย์ข้อที่ 8: การเปรียบเทียบมากกว่าหรือเท่ากับ

คำถาม: จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

2 ** 3 >= 9

แนวคิด

  • ยกกำลังก่อน
  • เปรียบเทียบ

เฉลย

  1. 2 ** 3 คำนวณก่อน ได้ 8
  2. นิพจน์กลายเป็น 8 >= 9
  3. ได้ผลลัพธ์ False

คำตอบ: False

โจทย์ข้อที่ 9: การเปรียบเทียบน้อยกว่า

คำถาม: จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

(100 / 10) < 10.0

แนวคิด

  • หารก่อน (ระวังผลลัพธ์เป็น float)
  • เปรียบเทียบ

เฉลย

  1. (100 / 10) คำนวณก่อน ได้ 10.0
  2. นิพจน์กลายเป็น 10.0 < 10.0
  3. ได้ผลลัพธ์ False

คำตอบ: False

โจทย์ข้อที่ 10: การเปรียบเทียบที่มีตัวแปรผสม

คำถาม: กำหนดให้ a = 5, b = 2 จงหาผลลัพธ์ของนิพจน์ Python ต่อไปนี้:

(a * b) <= (a + b)

แนวคิด

  • แทนค่าตัวแปร
  • คูณและบวกก่อน
  • เปรียบเทียบ

เฉลย

  1. แทนค่า: (5 * 2) <= (5 + 2)
  2. (5 * 2) คำนวณก่อน ได้ 10
  3. (5 + 2) คำนวณก่อน ได้ 7
  4. นิพจน์กลายเป็น 10 <= 7
  5. ได้ผลลัพธ์ False

คำตอบ: False
