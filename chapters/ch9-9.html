การเรียนรู้เทคนิคการติดตามการทำงานของโปรแกรมเพื่อหาผลลัพธ์อย่างแม่นยำ

ในบทเรียนนี้ เราจะมาเรียนรู้เทคนิคที่สำคัญอย่างยิ่งในการทำความเข้าใจการทำงานของโปรแกรมคอมพิวเตอร์ นั่นคือ การแกะรอยโปรแกรม (Program Tracing) การแกะรอยโปรแกรมคือกระบวนการติดตามการเปลี่ยนแปลงค่าของตัวแปรและลำดับการทำงานของคำสั่งทีละบรรทัด เพื่อให้สามารถคาดการณ์ผลลัพธ์สุดท้ายของโปรแกรมได้อย่างถูกต้อง ซึ่งเป็นทักษะที่จำเป็นอย่างยิ่งสำหรับการวิเคราะห์อัลกอริทึม การดีบัก (Debugging) และการทำความเข้าใจโค้ดที่ซับซ้อน

9.9.1 การแกะรอยโปรแกรมคืออะไร?

การแกะรอยโปรแกรม (Program Tracing) คือ การจำลองการทำงานของโปรแกรมในสมองหรือบนกระดาษ โดยการไล่ดูคำสั่งทีละบรรทัด และบันทึกการเปลี่ยนแปลงค่าของตัวแปรทุกตัวที่เกี่ยวข้อง ผลลัพธ์ที่ได้จากการแกะรอยโปรแกรมคือสถานะของโปรแกรมในแต่ละช่วงเวลา และผลลัพธ์สุดท้ายที่โปรแกรมจะแสดงออกมา

ทำไมต้องแกะรอยโปรแกรม?

  • ทำความเข้าใจ: ช่วยให้เข้าใจว่าโปรแกรมทำงานอย่างไรในแต่ละขั้นตอน
  • คาดการณ์ผลลัพธ์: สามารถหาผลลัพธ์ของโปรแกรมได้โดยไม่ต้องรันจริง
  • หาข้อผิดพลาด (Debugging): เมื่อโปรแกรมทำงานผิดพลาด การแกะรอยจะช่วยให้ pinpoint (ระบุตำแหน่ง) ของข้อผิดพลาดได้ง่ายขึ้น
  • เตรียมสอบ: ข้อสอบ สอวน. คอมพิวเตอร์ มักมีโจทย์ให้แกะรอยโปรแกรมเพื่อหาผลลัพธ์

9.9.2 วิธีการแกะรอยโปรแกรม

การแกะรอยโปรแกรมทำได้ดีที่สุดโดยการสร้าง ตารางติดตามตัวแปร (Trace Table)

ขั้นตอนการแกะรอย:

  1. สร้างตาราง: สร้างตารางที่มีคอลัมน์สำหรับ:
    • บรรทัด/รอบ: ระบุหมายเลขบรรทัดที่กำลังประมวลผล หรือรอบของลูป
    • คำสั่ง: คำสั่งที่กำลังถูกประมวลผล
    • คอลัมน์สำหรับตัวแปรแต่ละตัว: สร้างคอลัมน์สำหรับตัวแปรทุกตัวที่ปรากฏในโปรแกรม
    • ผลลัพธ์ที่พิมพ์: คอลัมน์สำหรับบันทึกสิ่งที่โปรแกรมพิมพ์ออกมา
  2. กำหนดค่าเริ่มต้น: บันทึกค่าเริ่มต้นของตัวแปรที่ถูกกำหนดไว้ในโปรแกรม (ถ้ามี)
  3. ประมวลผลทีละบรรทัด/รอบ:
    • อ่านคำสั่งทีละบรรทัดตามลำดับ
    • ประเมินนิพจน์ทางขวาของเครื่องหมายเท่ากับ (=) หรือเงื่อนไขของ if / while
    • อัปเดตค่าของตัวแปรที่อยู่ทางซ้ายของเครื่องหมายเท่ากับ
    • บันทึกค่าที่เปลี่ยนแปลงในตาราง
    • ถ้าเป็นคำสั่ง print() ให้บันทึกสิ่งที่พิมพ์ลงในคอลัมน์ "ผลลัพธ์ที่พิมพ์"
  4. วนซ้ำ (สำหรับลูป): หากเจอคำสั่งลูป (while) ให้ทำซ้ำขั้นตอนที่ 3 สำหรับแต่ละรอบของลูป จนกว่าเงื่อนไขของลูปจะเป็นเท็จ
  5. สิ้นสุด: ทำเช่นนี้ไปเรื่อยๆ จนกว่าจะถึงจุดสิ้นสุดของโปรแกรม

9.9.3 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ (การแกะรอยโปรแกรม)

เอกสารนี้รวบรวมตัวอย่างโจทย์พื้นฐานสำหรับการทำความเข้าใจการแกะรอยโปรแกรมและการใช้ตารางติดตาม เพื่อเตรียมความพร้อมสำหรับการสอบ สอวน. คอมพิวเตอร์ครับ

โจทย์ข้อที่ 1: การแกะรอยโปรแกรมลำดับขั้นตอนพื้นฐาน

คำถาม: กำหนดรหัส Python ต่อไปนี้

y = x + 3
z = y * 2
print(z)

  • ติดตามค่า x, y, z ตามลำดับบรรทัด

9.9.4 ตัวอย่างข้อสอบฝึกทำ

เอกสารนี้รวบรวมตัวอย่างข้อสอบสำหรับนักเรียนได้ฝึกทำในหัวข้อ "การแกะรอยโปรแกรม (Program Tracing) เพื่อหาผลลัพธ์" เพื่อเสริมสร้างความเข้าใจและเตรียมความพร้อมสำหรับการสอบ สอวน. คอมพิวเตอร์ครับ

โจทย์ข้อที่ 6: การแกะรอยโปรแกรม (การคำนวณสะสม)

คำถาม: กำหนดรหัส Python ต่อไปนี้

total = 0
for_loop_count = 0
while for_loop_count < 4:
    total = total + (for_loop_count * 10)
    for_loop_count = for_loop_count + 1
print(total)

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ติดตาม total และ for_loop_count ในแต่ละรอบของลูป while

เฉลย

รอบ 1: total = 0 + (0 × 10) = 0, for_loop_count = 1

รอบ 2: total = 0 + (1 × 10) = 10, for_loop_count = 2

รอบ 3: total = 10 + (2 × 10) = 30, for_loop_count = 3

รอบ 4: total = 30 + (3 × 10) = 60, for_loop_count = 4

คำตอบ: 60

โจทย์ข้อที่ 7: การแกะรอยโปรแกรม (เงื่อนไขเริ่มต้นลูป)

คำถาม: กำหนดรหัส Python ต่อไปนี้

start_val = 20

if start_val > 10:
    i = start_val
    while i < 25:
        print(i)
        i = i + 3
else:
    print("Start value is too small.")
print("End of program.")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ตรวจสอบเงื่อนไข if start_val > 10 ก่อน
  • ถ้าเป็นจริง ลูป while จะทำงาน

เฉลย

เงื่อนไข: 20 > 10 เป็น True

i = 20, ลูป while:

  • รอบ 1: i = 20 (< 25), พิมพ์ 20, i = 23
  • รอบ 2: i = 23 (< 25), พิมพ์ 23, i = 26
  • รอบ 3: i = 26 (≥ 25), ออกจากลูป

คำตอบ:

20
23
End of program.

โจทย์ข้อที่ 8: การแกะรอยโปรแกรม (การนับรอบ)

คำถาม: กำหนดรหัส Python ต่อไปนี้

counter = 0
value = 100
while value > 1:
    value = value // 3
    counter = counter + 1
print(counter)

จงหาจำนวนรอบที่ลูปทำงาน และค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ติดตาม value และ counter ในแต่ละรอบ
  • สังเกตเงื่อนไข value > 1

เฉลย

รอบ 1: value = 100 // 3 = 33, counter = 1

รอบ 2: value = 33 // 3 = 11, counter = 2

รอบ 3: value = 11 // 3 = 3, counter = 3

รอบ 4: value = 3 // 3 = 1, counter = 4

รอบ 5: value = 1 (≤ 1), ออกจากลูป

คำตอบ: จำนวนรอบ 4, ผลลัพธ์ 4

โจทย์ข้อที่ 9: การแกะรอยโปรแกรม (การประมวลผลข้อความ)

คำถาม: กำหนดรหัส Python ต่อไปนี้

text = "Python"
index = 0
result_text = ""
while index < len(text):
    if index % 2 == 0:
        result_text = result_text + text[index]
    index = index + 1
print(result_text)

(หมายเหตุ: len(text) คือความยาวของข้อความ, text[index] คือตัวอักษรที่ตำแหน่ง index โดยเริ่มจาก 0)
จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ติดตาม index และ result_text ในแต่ละรอบ
  • index % 2 == 0 หมายถึงตำแหน่งคู่ (0, 2, 4, ...)

เฉลย

"Python" มีความยาว 6 ตัวอักษร (P=0, y=1, t=2, h=3, o=4, n=5)

รอบ 1: index=0 (คู่), result_text += "P" → "P"

รอบ 2: index=1 (คี่), ข้าม

รอบ 3: index=2 (คู่), result_text += "t" → "Pt"

รอบ 4: index=3 (คี่), ข้าม

รอบ 5: index=4 (คู่), result_text += "o" → "Pto"

รอบ 6: index=5 (คี่), ข้าม

คำตอบ: "Pto"

โจทย์ข้อที่ 10: การแกะรอยโปรแกรม (การคำนวณที่ซับซ้อนและเงื่อนไข)

  • สังเกตว่าการอัปเดต a หรือ b ขึ้นอยู่กับ count เป็นคู่หรือคี่
