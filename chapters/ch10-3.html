บทที่ 10.3: การวิเคราะห์จำนวนครั้งของการคิดคำนวณในกระบวนการทำงาน

การฝึกฝนทักษะการวิเคราะห์ประสิทธิภาพของอัลกอริทึมผ่านการนับจำนวนครั้งของการดำเนินการพื้นฐาน

เนื้อหาในบทเรียน

  • 10.3.1 ความหมายของการวิเคราะห์จำนวนครั้งของการคิดคำนวณ
  • 10.3.2 วิธีการนับจำนวนครั้งของการคิดคำนวณ
  • 10.3.3 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ
  • 10.3.4 ตัวอย่างข้อสอบฝึกทำ

ในบทเรียนนี้ เราจะฝึกฝนทักษะสำคัญในการคิดเชิงวิเคราะห์ นั่นคือ การวิเคราะห์จำนวนครั้งของการคิดคำนวณ หรือการประเมินว่าขั้นตอนวิธี (Algorithm) หรือโปรแกรมหนึ่งๆ ใช้ทรัพยากร (เช่น เวลาในการประมวลผล) ไปมากน้อยเพียงใด โดยการนับจำนวนครั้งของการดำเนินการพื้นฐานต่างๆ ซึ่งเป็นสิ่งจำเป็นอย่างยิ่งสำหรับการออกแบบและเลือกใช้อัลกอริทึมที่มีประสิทธิภาพในวิทยาการคอมพิวเตอร์

10.3.1 ความหมายของการวิเคราะห์จำนวนครั้งของการคิดคำนวณ

การวิเคราะห์จำนวนครั้งของการคิดคำนวณ (Analysis of Computational Steps/Operations) คือ กระบวนการที่เราประเมินประสิทธิภาพของขั้นตอนวิธี โดยการนับจำนวนครั้งที่คำสั่งพื้นฐานต่างๆ ถูกดำเนินการเมื่อโปรแกรมทำงานจนเสร็จสิ้น

ทำไมต้องวิเคราะห์?

1. ประสิทธิภาพ:

เพื่อเปรียบเทียบว่าขั้นตอนวิธีใดทำงานได้เร็วกว่าหรือใช้ทรัพยากรน้อยกว่า เมื่อต้องจัดการกับข้อมูลขนาดใหญ่

2. การคาดการณ์:

เพื่อคาดการณ์ว่าโปรแกรมจะใช้เวลานานเท่าใดในการประมวลผลข้อมูลขนาดต่างๆ

3. การออกแบบ:

เพื่อช่วยในการออกแบบอัลกอริทึมที่มีประสิทธิภาพสูงสุด

การดำเนินการพื้นฐาน (Basic Operations):

ในการวิเคราะห์ เราจะนับการดำเนินการที่เป็นหน่วยย่อยที่สุดของการประมวลผล เช่น:

ประเภทการดำเนินการ สัญลักษณ์/ตัวอย่าง คำอธิบาย
การกำหนดค่า = Assignment: การกำหนดค่าให้ตัวแปร
การคำนวณทางคณิตศาสตร์ +, -, *, /, %, ** Arithmetic: การดำเนินการทางคณิตศาสตร์
การเปรียบเทียบ ==, !=, <, <=, >, >= Comparison: การเปรียบเทียบค่า
การรับข้อมูลนำเข้า INPUT Input: การรับข้อมูลจากผู้ใช้
การแสดงผล PRINT Output: การแสดงผลลัพธ์
การเข้าถึงหน่วยความจำ การเข้าถึงค่าในตัวแปร Memory Access: การอ่านค่าจากตัวแปร

10.3.2 วิธีการนับจำนวนครั้งของการคิดคำนวณ

การนับจำนวนครั้งของการคิดคำนวณจะขึ้นอยู่กับโครงสร้างของขั้นตอนวิธี:

ก. โครงสร้างแบบลำดับขั้นตอน (Sequential Structure)

นับจำนวนครั้งของการดำเนินการพื้นฐานในแต่ละบรรทัดตามลำดับ

ตัวอย่าง:

SET x TO 5      # 1 Assignment
SET y TO x + 3  # 1 Arithmetic (+), 1 Assignment
PRINT y         # 1 Print

รวม: 2 Assignment, 1 Arithmetic, 1 Print

ข. โครงสร้างแบบเลือกทำ (Conditional Structure: IF-ELSE)

นับจำนวนครั้งของการดำเนินการพื้นฐานในส่วนที่ทำงานจริง

หากโจทย์ต้องการการวิเคราะห์ในกรณีที่เลวร้ายที่สุด (Worst-Case) ให้เลือกเส้นทางของเงื่อนไขที่ทำให้มีการดำเนินการมากที่สุด

ตัวอย่าง:

IF x > 0 THEN     # 1 Comparison
  PRINT "Positive"  # 1 Print (ถ้าเงื่อนไขเป็น True)
ELSE
  PRINT "Not Positive" # 1 Print (ถ้าเงื่อนไขเป็น False)
END IF

ในทุกกรณี: 1 Comparison, 1 Print

ค. โครงสร้างแบบวนซ้ำ (Repetitive Structure: WHILE Loop)

1. นับจำนวนรอบที่ลูปทำงาน:

นี่คือปัจจัยหลักที่ส่งผลต่อจำนวนครั้งของการดำเนินการ

2. นับการดำเนินการภายในลูป:

คำสั่งที่อยู่ในบล็อกของลูปจะถูกทำซ้ำตามจำนวนรอบ

3. นับการตรวจสอบเงื่อนไขลูป:

เงื่อนไขของลูปจะถูกตรวจสอบในทุกๆ รอบที่ลูปทำงาน และอีก 1 ครั้งเมื่อเงื่อนไขเป็นเท็จเพื่อออกจากลูป

ตัวอย่าง:

SET i TO 1          # 1 Assignment (ก่อนลูป)
WHILE i <= 3 DO     # การตรวจสอบเงื่อนไข (4 ครั้ง: 3 True + 1 False)
  PRINT i           # 1 Print × 3 รอบ = 3 Print
  i = i + 1         # (1 Arithmetic + 1 Assignment) × 3 รอบ = 3 Arithmetic, 3 Assignment
END WHILE

รวม: 4 Assignment (1+3), 3 Arithmetic, 4 Comparison, 3 Print

10.3.3 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ

ในส่วนนี้ เราจะมาฝึกทำความเข้าใจและวิเคราะห์จำนวนครั้งของการคิดคำนวณในขั้นตอนวิธีที่กำหนดให้

โจทย์ข้อที่ 1: การวิเคราะห์รหัสเทียม (ลำดับขั้นตอน)

คำถาม: กำหนดรหัสเทียมต่อไปนี้

START
  INPUT num1       # บรรทัดที่ 1
  INPUT num2       # บรรทัดที่ 2
  SET sum TO num1 + num2 # บรรทัดที่ 3
  SET product TO num1 * num2 # บรรทัดที่ 4
  PRINT sum        # บรรทัดที่ 5
  PRINT product    # บรรทัดที่ 6
END

จงวิเคราะห์จำนวนครั้งของการดำเนินการพื้นฐาน (Input, Arithmetic, Assignment, Print) เมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ไล่คำสั่งทีละบรรทัดและนับการดำเนินการแต่ละประเภท

เฉลย

  • บรรทัดที่ 1: INPUT num1 (1 Input)
  • บรรทัดที่ 2: INPUT num2 (1 Input)
  • บรรทัดที่ 3: SET sum TO num1 + num2 (1 Arithmetic: +, 1 Assignment: =)
  • บรรทัดที่ 4: SET product TO num1 * num2 (1 Arithmetic: *, 1 Assignment: =)
  • บรรทัดที่ 5: PRINT sum (1 Print)
  • บรรทัดที่ 6: PRINT product (1 Print)

รวมจำนวนครั้งของการดำเนินการ:

  • Input: 2 ครั้ง
  • Arithmetic: 2 ครั้ง
  • Assignment: 2 ครั้ง
  • Print: 2 ครั้ง

คำตอบ: Input 2, Arithmetic 2, Assignment 2, Print 2

โจทย์ข้อที่ 2: การวิเคราะห์ผังงาน (การเลือกทำ IF-ELSE)

คำถาม: กำหนดผังงานต่อไปนี้

🔴 Start
      ↓
📄 Input Score
      ↓
🔷 Score >= 50?
   ↙   ↘
 Yes    No
  ↓      ↓
📄 Print  📄 Print
 "ผ่าน"   "ไม่ผ่าน"
     ↘     ↙
       ↓
    🔴 End

จงวิเคราะห์จำนวนครั้งของการดำเนินการพื้นฐาน (Input, Comparison, Print, Assignment) ในกรณีที่เลวร้ายที่สุด (Worst-Case)

แนวคิด

  • ระบุเส้นทางที่ทำงานมากที่สุด
  • นับการดำเนินการในเส้นทางนั้น

เฉลย

ในผังงานนี้ ไม่ว่า Score >= 50 จะเป็น True หรือ False จำนวนการดำเนินการจะเท่ากัน:

  1. Start: (ไม่นับ)
  2. Input Score: (1 Input)
  3. Score >= 50?: (1 Comparison)
  4. Print "ผ่าน" (ถ้าเงื่อนไขเป็น True) หรือ Print "ไม่ผ่าน" (ถ้าเงื่อนไขเป็น False): (1 Print)
  5. End: (ไม่นับ)

รวมจำนวนครั้งของการดำเนินการ:

  • Input: 1 ครั้ง
  • Comparison: 1 ครั้ง
  • Print: 1 ครั้ง

คำตอบ: Input 1, Comparison 1, Print 1

โจทย์ข้อที่ 3: การวิเคราะห์รหัสเทียม (การวนซ้ำ WHILE)

คำถาม: กำหนดรหัสเทียมต่อไปนี้

START
  SET i TO 1       # บรรทัดที่ 1
  SET total TO 0   # บรรทัดที่ 2
  WHILE i <= 3 DO  # บรรทัดที่ 3 (เงื่อนไขลูป)
    total = total + i # บรรทัดที่ 4
    i = i + 1      # บรรทัดที่ 5
  END WHILE
  PRINT total      # บรรทัดที่ 6
END

จงวิเคราะห์จำนวนครั้งของการดำเนินการพื้นฐาน (Assignment, Comparison, Arithmetic, Print) เมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • นับการดำเนินการก่อนลูป
  • นับการดำเนินการภายในลูป (คูณด้วยจำนวนรอบที่ลูปทำงาน)
  • นับการตรวจสอบเงื่อนไขลูป (จำนวนรอบ + 1 ครั้งสุดท้าย)

เฉลย

ก่อนลูป:
  • บรรทัดที่ 1: SET i TO 1 (1 Assignment)
  • บรรทัดที่ 2: SET total TO 0 (1 Assignment)
ภายในลูป:

ลูป WHILE i <= 3 จะทำงานเมื่อ i เป็น 1, 2, 3 (รวม 3 รอบ)

  • การตรวจสอบเงื่อนไขลูป (บรรทัดที่ 3): i <= 3 จะถูกตรวจสอบ 4 ครั้ง (3 ครั้งเป็น True, 1 ครั้งเป็น False เพื่อออกจากลูป) = 4 Comparisons
  • การดำเนินการในแต่ละรอบ (3 รอบ):
    • บรรทัดที่ 4: total = total + i (1 Arithmetic: +, 1 Assignment: =)
    • บรรทัดที่ 5: i = i + 1 (1 Arithmetic: +, 1 Assignment: =)
  • รวมภายในลูป 1 รอบ: 2 Arithmetic, 2 Assignment
  • รวม 3 รอบ: $3 \times (2 \text{ Arithmetic}, 2 \text{ Assignment}) = 6 \text{ Arithmetic}, 6 \text{ Assignment}$
หลังลูป:
  • บรรทัดที่ 6: PRINT total (1 Print)

รวมจำนวนครั้งของการดำเนินการทั้งหมด:

  • Assignment: $1 + 1 + 6 = 8$ ครั้ง
  • Arithmetic: 6 ครั้ง
  • Comparison: 4 ครั้ง
  • Print: 1 ครั้ง

คำตอบ: Assignment 8, Arithmetic 6, Comparison 4, Print 1

โจทย์ข้อที่ 4: การวิเคราะห์ผังงาน (การวนซ้ำและเลือกทำ)

คำถาม: กำหนดผังงานต่อไปนี้

🔴 Start
      ↓
📦 num = 1, sum_even = 0, sum_odd = 0
      ↓
🔷 num <= 5?
   ↙   ↘
 Yes    No
  ↓      ↓
🔷 num % 2 == 0?  📄 Print sum_even
 ↙   ↘         📄 Print sum_odd
Yes   No           ↓
 ↓     ↓        🔴 End
📦 sum_even = 📦 sum_odd =
sum_even + num sum_odd + num
  ↓       ↓
   ↘     ↙
📦 num = num + 1
       ↓
    (ไปยัง num <= 5?)

จงวิเคราะห์จำนวนครั้งของการดำเนินการพื้นฐาน (Assignment, Comparison, Arithmetic, Print) เมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ไล่ตามลูกศรและติดตามค่า num, sum_even, sum_odd ในแต่ละรอบ
  • นับการดำเนินการในแต่ละสัญลักษณ์และเส้นทางที่ถูกเลือก

เฉลย

การกำหนดค่าเริ่มต้น (ก่อนลูป):
  • num = 1 (1 Assignment)
  • sum_even = 0 (1 Assignment)
  • sum_odd = 0 (1 Assignment)
ภายในลูป:

ลูป num <= 5 จะทำงานเมื่อ num เป็น 1, 2, 3, 4, 5 (รวม 5 รอบ)

  • การตรวจสอบเงื่อนไขลูป (num <= 5?): 6 ครั้ง (5 True, 1 False) = 6 Comparisons
  • การตรวจสอบเงื่อนไข if (num % 2 == 0?): 5 ครั้ง (1 ครั้งต่อรอบ) = 5 Comparisons
  • การดำเนินการภายใน if-else (5 รอบ):
    • num % 2 == 0 (1 Arithmetic: %, 1 Comparison: ==)
    • ถ้า True: sum_even = sum_even + num (1 Arithmetic: +, 1 Assignment: =)
    • ถ้า False: sum_odd = sum_odd + num (1 Arithmetic: +, 1 Assignment: =)
    • num = num + 1 (1 Arithmetic: +, 1 Assignment: =)
  • รวม 1 รอบ: (1 Arithmetic: %, 1 Comparison: ==) + (1 Arithmetic: +, 1 Assignment: =) + (1 Arithmetic: +, 1 Assignment: =)
  • รวม 5 รอบ:
    • Arithmetic: $5 \times (1 \text{ (for %)} + 2 \text{ (for +)}) = 15$ ครั้ง
    • Assignment: $5 \times 2 = 10$ ครั้ง
หลังลูป:
  • Print sum_even (1 Print)
  • Print sum_odd (1 Print)

รวมจำนวนครั้งของการดำเนินการทั้งหมด:

  • Assignment: $1 + 1 + 1 + 10 = 13$ ครั้ง
  • Arithmetic: 15 ครั้ง
  • Comparison: $6 + 5 = 11$ ครั้ง
  • Print: $1 + 1 = 2$ ครั้ง

คำตอบ: Assignment 13, Arithmetic 15, Comparison 11, Print 2

โจทย์ข้อที่ 5: การวิเคราะห์รหัสเทียม (เงื่อนไขซับซ้อนหลายชั้น)

คำถาม: กำหนดรหัสเทียมต่อไปนี้

START
  INPUT age              # บรรทัดที่ 1
  INPUT has_license      # บรรทัดที่ 2
  INPUT has_car          # บรรทัดที่ 3
  IF age >= 18 AND has_license == TRUE THEN # บรรทัดที่ 4
    IF has_car == TRUE THEN  # บรรทัดที่ 5
      PRINT "คุณสามารถขับรถของตัวเองได้" # บรรทัดที่ 6
    ELSE                     # บรรทัดที่ 7
      PRINT "คุณสามารถขับรถได้ แต่ไม่มีรถ" # บรรทัดที่ 8
    END IF
  ELSE IF age >= 18 AND has_license == FALSE THEN # บรรทัดที่ 9
    PRINT "คุณมีอายุพอ แต่ยังไม่มีใบขับขี่" # บรรทัดที่ 10
  ELSE                     # บรรทัดที่ 11
    PRINT "คุณยังเด็กเกินไป" # บรรทัดที่ 12
  END IF
END

จงวิเคราะห์จำนวนครั้งของการดำเนินการพื้นฐาน (Input, Comparison, Arithmetic, Print) ในกรณีที่ผู้ใช้ป้อน age = 25, has_license = TRUE, และ has_car = FALSE

แนวคิด

  • ไล่ตามเส้นทางที่กำหนดโดย Input ที่ให้มา
  • นับการดำเนินการในเส้นทางนั้น

เฉลย

เส้นทางการทำงาน: บรรทัด 1, 2, 3 → 4 (True) → 5 (False) → 8

  1. Input age: (1 Input)
  2. Input has_license: (1 Input)
  3. Input has_car: (1 Input)
  4. IF age >= 18 AND has_license == TRUE THEN: (2 Comparisons: >=, ==, 1 Logical: AND)
    • 25 >= 18 (True)
    • TRUE == TRUE (True)
    • True AND True (True)
  5. IF has_car == TRUE THEN: (1 Comparison: ==)
    • FALSE == TRUE (False)
  6. ELSE: (ไม่มีการดำเนินการ)
  7. PRINT "คุณสามารถขับรถได้ แต่ไม่มีรถ": (1 Print)

รวมจำนวนครั้งของการดำเนินการทั้งหมด:

  • Input: 3 ครั้ง
  • Comparison: $2 + 1 = 3$ ครั้ง
  • Logical: 1 ครั้ง
  • Print: 1 ครั้ง

คำตอบ: Input 3, Comparison 3, Logical 1, Print 1

10.3.4 ตัวอย่างข้อสอบฝึกทำ

โจทย์ข้อที่ 6: การวิเคราะห์รหัสเทียม (การคำนวณสะสมในลูป)

คำถาม: กำหนดรหัสเทียมต่อไปนี้

START
  SET i TO 1
  SET total_sum TO 0
  WHILE i <= 5 DO
    total_sum = total_sum + i
    i = i + 1
  END WHILE
