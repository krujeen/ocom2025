บทที่ 9.5: ลำดับการทำงานเลือกทำ (if-then-else)

การเรียนรู้โครงสร้างควบคุมแบบเลือกทำและการสร้างเงื่อนไขในโปรแกรม

ในบทเรียนนี้ เราจะมาเรียนรู้เกี่ยวกับ ลำดับการทำงานแบบเลือกทำ (Conditional Execution) ซึ่งเป็นโครงสร้างควบคุมที่สำคัญอย่างยิ่งในการเขียนโปรแกรมคอมพิวเตอร์ การทำงานแบบเลือกทำช่วยให้โปรแกรมสามารถตัดสินใจว่าจะทำคำสั่งชุดใดตามเงื่อนไขที่กำหนด ทำให้โปรแกรมมีความยืดหยุ่นและสามารถตอบสนองต่อสถานการณ์ต่างๆ ได้

9.5.1 การทำงานแบบมีเงื่อนไข (Conditional Execution)

การทำงานแบบมีเงื่อนไข คือ การที่โปรแกรมจะประมวลผลคำสั่งบางชุด ก็ต่อเมื่อเงื่อนไขที่กำหนดเป็นจริง เท่านั้น หากเงื่อนไขเป็นเท็จ โปรแกรมอาจจะข้ามคำสั่งชุดนั้นไป หรือไปทำคำสั่งชุดอื่นแทน

แนวคิดหลัก

  • "ถ้าสิ่งนี้เป็นจริง, ให้ทำสิ่งนั้น" หรือ "ถ้าสิ่งนี้เป็นจริง, ให้ทำสิ่งนั้น; มิฉะนั้น, ให้ทำสิ่งอื่น"
  • การตัดสินใจ: โปรแกรมใช้ผลลัพธ์จากนิพจน์เปรียบเทียบ (ซึ่งเป็นค่า True หรือ False) ในการตัดสินใจ

9.5.2 คำสั่ง if (if Statement)

คำสั่ง if เป็นโครงสร้างการเลือกทำที่ง่ายที่สุด โปรแกรมจะทำคำสั่งที่อยู่ภายใต้ if ก็ต่อเมื่อเงื่อนไขเป็นจริงเท่านั้น หากเงื่อนไขเป็นเท็จ โปรแกรมจะข้ามคำสั่งเหล่านั้นไปและทำคำสั่งถัดจากบล็อก if ทันที

รูปแบบในภาษา Python

if condition:
    # คำสั่งที่จะทำเมื่อ condition เป็น True
    # (ต้องมี indent หรือการเยื้อง)

ตัวอย่าง

score = 75

if score >= 50:
    print("คุณสอบผ่าน!")
print("โปรแกรมจบ.")

คำอธิบาย:

  • ถ้า score (75) มากกว่าหรือเท่ากับ 50 (ซึ่งเป็น True) โปรแกรมจะพิมพ์ "คุณสอบผ่าน!"
  • จากนั้นจะพิมพ์ "โปรแกรมจบ."

9.5.3 คำสั่ง if-else (if-else Statement)

คำสั่ง if-else ใช้เมื่อโปรแกรมต้องการทำคำสั่งชุดหนึ่งถ้าเงื่อนไขเป็นจริง และทำคำสั่งอีกชุดหนึ่งถ้าเงื่อนไขเป็นเท็จ (คือมีทางเลือก 2 ทางเสมอ)

รูปแบบในภาษา Python

if condition:
    # คำสั่งที่จะทำเมื่อ condition เป็น True
else:
    # คำสั่งที่จะทำเมื่อ condition เป็น False

ตัวอย่าง

age = 17

if age >= 18:
    print("คุณสามารถโหวตได้")
else:
    print("คุณยังไม่สามารถโหวตได้")
print("โปรแกรมจบ.")

คำอธิบาย:

  • ถ้า age (17) มากกว่าหรือเท่ากับ 18 (ซึ่งเป็น False) โปรแกรมจะข้ามบล็อก if ไปทำบล็อก else
  • โปรแกรมจะพิมพ์ "คุณยังไม่สามารถโหวตได้"
  • จากนั้นจะพิมพ์ "โปรแกรมจบ."

9.5.4 คำสั่ง if-elif-else (if-elif-else Statement)

คำสั่ง if-elif-else ใช้เมื่อมีหลายเงื่อนไขที่ต้องพิจารณา โปรแกรมจะตรวจสอบเงื่อนไขจากบนลงล่าง และจะทำคำสั่งในบล็อกแรกที่เงื่อนไขเป็นจริงเท่านั้น หากไม่มีเงื่อนไขใดเป็นจริงเลย โปรแกรมจะทำคำสั่งในบล็อก else (ถ้ามี)

รูปแบบในภาษา Python

if condition1:
    # คำสั่งเมื่อ condition1 เป็น True
elif condition2:
    # คำสั่งเมื่อ condition1 เป็น False แต่ condition2 เป็น True
elif condition3:
    # คำสั่งเมื่อ condition1, condition2 เป็น False แต่ condition3 เป็น True
else:
    # คำสั่งเมื่อทุก condition เป็น False

ตัวอย่าง

grade = 85

if grade >= 90:
    print("ได้เกรด A")
elif grade >= 80:
    print("ได้เกรด B")
elif grade >= 70:
    print("ได้เกรด C")
else:
    print("ได้เกรด D หรือ F")

คำอธิบาย:

  • grade (85) ไม่เข้าเงื่อนไข grade >= 90 (False)
  • โปรแกรมจะตรวจสอบ grade >= 80 (85 >= 80 ซึ่งเป็น True)
  • โปรแกรมจะพิมพ์ "ได้เกรด B" และข้ามบล็อก elif และ else ที่เหลือ

9.5.5 คำสั่ง if ซ้อน if (Nested if Statements)

คำสั่ง if ซ้อน if คือ การมีคำสั่ง if (หรือ if-else, if-elif-else) อยู่ภายในบล็อกของคำสั่ง if (หรือ else, elif) อื่นๆ เพื่อสร้างเงื่อนไขที่ซับซ้อนและละเอียดอ่อนยิ่งขึ้น

รูปแบบในภาษา Python

if condition1:
    # คำสั่งเมื่อ condition1 เป็น True
    if condition2:
        # คำสั่งเมื่อ condition1 และ condition2 เป็น True
    else:
        # คำสั่งเมื่อ condition1 เป็น True แต่ condition2 เป็น False
else:
    # คำสั่งเมื่อ condition1 เป็น False

ตัวอย่าง

age = 20
has_license = True

if age >= 18:
    print("คุณมีอายุพอที่จะขับรถได้")
    if has_license:
        print("คุณสามารถขับรถได้!")
    else:
        print("แต่คุณยังไม่มีใบขับขี่")
else:
    print("คุณยังเด็กเกินไปที่จะขับรถ")

คำอธิบาย:

  • age (20) มากกว่าหรือเท่ากับ 18 (True) โปรแกรมจะเข้าบล็อก if แรก
  • พิมพ์ "คุณมีอายุพอที่จะขับรถได้"
  • จากนั้นตรวจสอบเงื่อนไขที่ซ้อนอยู่ has_license (True)
  • โปรแกรมจะเข้าบล็อก if ที่ซ้อนอยู่และพิมพ์ "คุณสามารถขับรถได้!"

9.5.6 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ

เอกสารนี้รวบรวมตัวอย่างโจทย์พื้นฐานสำหรับการทำความเข้าใจการทำงานแบบเลือกทำและการใช้งานโครงสร้าง if ต่างๆ เพื่อเตรียมความพร้อมสำหรับการสอบ สอวน. คอมพิวเตอร์ครับ

โจทย์ข้อที่ 1: คำสั่ง if เดี่ยว

คำถาม: กำหนดรหัส Python

temperature = 28

if temperature > 25:
    print("อากาศร้อน")
print("จบโปรแกรม")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ตรวจสอบเงื่อนไข temperature > 25 (28 > 25) ว่าเป็น True หรือ False
  • ถ้าเป็น True ทำคำสั่งในบล็อก if
  • ไม่ว่าจะเกิดอะไรขึ้น คำสั่ง print("จบโปรแกรม") จะถูกทำเสมอ

เฉลย

  1. temperature = 28
  2. if temperature > 25: (28 > 25 เป็น True)
  3. เข้าบล็อก if: print("อากาศร้อน") → แสดงผล "อากาศร้อน"
  4. print("จบโปรแกรม") → แสดงผล "จบโปรแกรม"

คำตอบ:
อากาศร้อน
จบโปรแกรม

โจทย์ข้อที่ 2: คำสั่ง if-else

คำถาม: กำหนดรหัส Python

score = 45

if score >= 50:
    print("ผ่าน")
else:
    print("ไม่ผ่าน")
print("ผลการสอบ")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ตรวจสอบเงื่อนไข score >= 50 (45 >= 50)
  • ถ้าเป็น True ทำบล็อก if, ถ้าเป็น False ทำบล็อก else

เฉลย

  1. score = 45
  2. if score >= 50: (45 >= 50 เป็น False)
  3. ข้ามบล็อก if ไปทำบล็อก else: print("ไม่ผ่าน") → แสดงผล "ไม่ผ่าน"
  4. print("ผลการสอบ") → แสดงผล "ผลการสอบ"

คำตอบ:
ไม่ผ่าน
ผลการสอบ

โจทย์ข้อที่ 3: คำสั่ง if-elif-else

คำถาม: กำหนดรหัส Python

points = 75

if points >= 90:
    print("ยอดเยี่ยม")
elif points >= 70:
    print("ดี")
else:
    print("พอใช้")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ตรวจสอบเงื่อนไขจากบนลงล่าง
  • เมื่อเงื่อนไขใดเป็นจริง จะทำบล็อกนั้นแล้วข้ามที่เหลือ

เฉลย

  1. points = 75
  2. if points >= 90: (75 >= 90 เป็น False)
  3. elif points >= 70: (75 >= 70 เป็น True)
  4. เข้าบล็อก elif: print("ดี") → แสดงผล "ดี"
  5. โปรแกรมจบ (ข้าม else ที่เหลือ)

คำตอบ: ดี

โจทย์ข้อที่ 4: คำสั่ง if ซ้อน if

คำถาม: กำหนดรหัส Python

age = 22
is_student = True

if age >= 18:
    if is_student:
        print("คุณเป็นนักศึกษาผู้ใหญ่")
    else:
        print("คุณเป็นผู้ใหญ่")
else:
    print("คุณยังไม่เป็นผู้ใหญ่")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ตรวจสอบเงื่อนไข if ภายนอกก่อน
  • ถ้าเงื่อนไขภายนอกเป็นจริง ค่อยเข้าไปตรวจสอบเงื่อนไข if ภายใน

เฉลย

  1. age = 22, is_student = True
  2. if age >= 18: (22 >= 18 เป็น True)
  3. เข้าบล็อก if ภายนอก:
  4. if is_student: (True เป็น True)
  5. เข้าบล็อก if ภายใน: print("คุณเป็นนักศึกษาผู้ใหญ่") → แสดงผล "คุณเป็นนักศึกษาผู้ใหญ่"
  6. โปรแกรมจบ

คำตอบ: คุณเป็นนักศึกษาผู้ใหญ่

โจทย์ข้อที่ 5: การทำงานแบบมีเงื่อนไข (ไม่มีการพิมพ์ผลลัพธ์)

คำถาม: กำหนดรหัส Python

x = 10
y = 20

if x > y:
    print("X มากกว่า Y")
elif x == y:
    print("X เท่ากับ Y")
else:
    # ไม่มีคำสั่ง print ในบล็อกนี้
    pass
print("สิ้นสุด")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ตรวจสอบเงื่อนไขแต่ละอัน
  • สังเกตว่าบล็อก else ไม่มีคำสั่ง print

เฉลย

  1. x = 10, y = 20
  2. if x > y: (10 > 20 เป็น False)
  3. elif x == y: (10 == 20 เป็น False)
  4. else: (เงื่อนไขทั้งหมดเป็น False)
  5. เข้าบล็อก else แต่ไม่มีคำสั่ง print
  6. print("สิ้นสุด") → แสดงผล "สิ้นสุด"

คำตอบ: สิ้นสุด

9.5.7 ตัวอย่างข้อสอบฝึกทำ

เอกสารนี้รวบรวมตัวอย่างข้อสอบสำหรับนักเรียนได้ฝึกทำในหัวข้อ "ลำดับการทำงานเลือกทำ" เพื่อเสริมสร้างความเข้าใจและเตรียมความพร้อมสำหรับการสอบ สอวน. คอมพิวเตอร์ครับ

โจทย์ข้อที่ 6: คำสั่ง if-else (กับตัวแปรที่เปลี่ยนแปลง)

คำถาม: กำหนดรหัส Python

num = 10
num = num * 2

if num > 20:
    print("ใหญ่")
else:
    print("เล็กหรือเท่ากับ")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ติดตามค่าของตัวแปร num ที่เปลี่ยนแปลงก่อนเข้าเงื่อนไข

เฉลย

  1. num = 10
  2. num = num * 2 → num = 10 * 2 = 20
  3. if num > 20: (20 > 20 เป็น False)
  4. เข้าบล็อก else: print("เล็กหรือเท่ากับ") → แสดงผล "เล็กหรือเท่ากับ"

คำตอบ: เล็กหรือเท่ากับ

โจทย์ข้อที่ 7: คำสั่ง if-elif-else (หลายเงื่อนไข)

คำถาม: กำหนดรหัส Python

value = 50

if value < 20:
    print("น้อยกว่า 20")
elif value < 50:
    print("น้อยกว่า 50")
elif value < 80:
    print("น้อยกว่า 80")
else:
    print("80 ขึ้นไป")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ตรวจสอบเงื่อนไขจากบนลงล่าง และหยุดเมื่อเจอเงื่อนไขแรกที่เป็นจริง

เฉลย

  1. value = 50
  2. if value < 20: (50 < 20 เป็น False)
  3. elif value < 50: (50 < 50 เป็น False)
  4. elif value < 80: (50 < 80 เป็น True)
  5. เข้าบล็อก elif ที่สาม: print("น้อยกว่า 80") → แสดงผล "น้อยกว่า 80"
  6. โปรแกรมจบ (ข้าม else ที่เหลือ)

คำตอบ: น้อยกว่า 80

โจทย์ข้อที่ 8: คำสั่ง if ซ้อน if (เงื่อนไขซับซ้อน)

คำถาม: กำหนดรหัส Python

is_member = True
total_purchase = 1200

if is_member:
    if total_purchase > 1000:
        print("รับส่วนลดพิเศษ")
    else:
        print("รับส่วนลดปกติ")
else:
    print("ไม่มีสิทธิ์ส่วนลด")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ตรวจสอบเงื่อนไขภายนอกก่อน แล้วค่อยตรวจสอบเงื่อนไขภายใน

เฉลย

  1. is_member = True, total_purchase = 1200
  2. if is_member: (True เป็น True)
  3. เข้าบล็อก if ภายนอก:
  4. if total_purchase > 1000: (1200 > 1000 เป็น True)
  5. เข้าบล็อก if ภายใน: print("รับส่วนลดพิเศษ") → แสดงผล "รับส่วนลดพิเศษ"

คำตอบ: รับส่วนลดพิเศษ

โจทย์ข้อที่ 9: การทำงานแบบมีเงื่อนไข (ไม่มีการพิมพ์ผลลัพธ์ในบางกรณี)

คำถาม: กำหนดรหัส Python

speed = 60

if speed > 80:
    print("เร็วเกินไป")
elif speed < 40:
    print("ช้าเกินไป")
# ไม่มี else
print("ขับขี่ปลอดภัย")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • สังเกตว่าไม่มีบล็อก else และค่าของ speed อาจไม่ตรงกับเงื่อนไข if หรือ elif

เฉลย

  1. speed = 60
  2. if speed > 80: (60 > 80 เป็น False)
  3. elif speed < 40: (60 < 40 เป็น False)
  4. ไม่มีบล็อก else และไม่มีเงื่อนไขใดเป็นจริง
  5. print("ขับขี่ปลอดภัย") → แสดงผล "ขับขี่ปลอดภัย"

คำตอบ: ขับขี่ปลอดภัย

โจทย์ข้อที่ 10: การทำงานแบบมีเงื่อนไข (การคำนวณในเงื่อนไข)

คำถาม: กำหนดรหัส Python

a = 5
b = 10

if (a + b) > 12:
    print("ผลรวมมาก")
elif (b - a) == 5:
    print("ผลต่างเท่ากับ 5")
else:
    print("อื่นๆ")

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • คำนวณนิพจน์ภายในเงื่อนไขก่อน แล้วค่อยตรวจสอบค่าความจริงของเงื่อนไขนั้นๆ

เฉลย

  1. a = 5, b = 10
  2. if (a + b) > 12: (5 + 10) > 12 → 15 > 12 เป็น True
  3. เข้าบล็อก if: print("ผลรวมมาก") → แสดงผล "ผลรวมมาก"
  4. โปรแกรมจบ (ข้าม elif และ else ที่เหลือ)

คำตอบ: ผลรวมมาก
