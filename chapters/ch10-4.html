บทที่ 10.4: การวิเคราะห์ผลลัพธ์เมื่อมีการเปลี่ยนแปลงวิธีการคิดในบางจุด

การฝึกฝนทักษะการวิเคราะห์ผลกระทบของการเปลี่ยนแปลงในอัลกอริทึมต่อผลลัพธ์สุดท้าย

เนื้อหาในบทเรียน

  • 10.4.1 ความหมายของการวิเคราะห์ผลลัพธ์เมื่อมีการเปลี่ยนแปลง
  • 10.4.2 วิธีการวิเคราะห์ผลลัพธ์เมื่อมีการเปลี่ยนแปลง
  • 10.4.3 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ
  • 10.4.4 ตัวอย่างข้อสอบฝึกทำ

ในบทเรียนนี้ เราจะฝึกฝนทักษะการคิดเชิงวิเคราะห์ขั้นสูงขึ้น นั่นคือ การวิเคราะห์ผลลัพธ์ของขั้นตอนวิธี (Algorithm Output) เมื่อมีการเปลี่ยนแปลงวิธีการคิด หรือคำสั่งบางส่วนในโปรแกรม การทำความเข้าใจว่าการเปลี่ยนแปลงเล็กน้อยในโค้ดสามารถส่งผลกระทบต่อผลลัพธ์สุดท้ายได้อย่างไร เป็นสิ่งสำคัญอย่างยิ่งในการแก้ไขข้อผิดพลาด (Debugging) การปรับปรุงประสิทธิภาพ และการพัฒนาโปรแกรมให้ตรงตามความต้องการ

10.4.1 ความหมายของการวิเคราะห์ผลลัพธ์เมื่อมีการเปลี่ยนแปลง

การวิเคราะห์ผลลัพธ์เมื่อมีการเปลี่ยนแปลงวิธีการคิดในบางจุด (Analysis of Output Changes due to Algorithm Modifications) คือ กระบวนการที่เราประเมินว่าผลลัพธ์ของโปรแกรมจะเปลี่ยนไปอย่างไร เมื่อมีการแก้ไขคำสั่ง, ค่าเริ่มต้น, เงื่อนไข, หรือการดำเนินการใดๆ ภายในขั้นตอนวิธี

ทำไมต้องวิเคราะห์การเปลี่ยนแปลง?

1. การดีบัก:

เมื่อโปรแกรมทำงานผิดพลาด การระบุว่าการเปลี่ยนแปลงในส่วนใดที่ทำให้เกิดปัญหาเป็นสิ่งสำคัญ

2. การปรับแต่ง:

เพื่อปรับปรุงอัลกอริทึมให้มีประสิทธิภาพดีขึ้น หรือให้ผลลัพธ์ที่แตกต่างออกไปตามที่ต้องการ

3. การทำความเข้าใจเชิงลึก:

ช่วยให้เข้าใจถึงความสัมพันธ์ระหว่างส่วนต่างๆ ของโค้ด และผลกระทบที่เกิดขึ้น

4. เตรียมสอบ:

ข้อสอบ สอวน. คอมพิวเตอร์ มักมีโจทย์ลักษณะนี้เพื่อทดสอบความเข้าใจตรรกะของโปรแกรม

10.4.2 วิธีการวิเคราะห์ผลลัพธ์เมื่อมีการเปลี่ยนแปลง

หัวใจสำคัญของการวิเคราะห์นี้คือการใช้เทคนิค การแกะรอยโปรแกรม (Program Tracing) ร่วมกับการเปรียบเทียบ

ขั้นตอนการวิเคราะห์:

1. ทำความเข้าใจโค้ดต้นฉบับ:

แกะรอยโปรแกรมต้นฉบับเพื่อหาผลลัพธ์ที่คาดหวัง

2. ระบุจุดที่เปลี่ยนแปลง:

หาว่าคำสั่ง, ค่า, หรือเงื่อนไขใดที่ถูกแก้ไข

3. แกะรอยโปรแกรมที่แก้ไขแล้ว:

  • เริ่มต้นแกะรอยโปรแกรมใหม่ตั้งแต่ต้น
  • เมื่อถึงจุดที่มีการเปลี่ยนแปลง ให้ประมวลผลตามคำสั่งที่แก้ไขใหม่นั้น
  • ติดตามผลกระทบของการเปลี่ยนแปลงนั้นต่อค่าของตัวแปรอื่นๆ และลำดับการทำงานของโปรแกรมที่เหลือ

4. เปรียบเทียบผลลัพธ์:

เปรียบเทียบผลลัพธ์สุดท้ายที่ได้จากโปรแกรมที่แก้ไขแล้ว กับผลลัพธ์จากโปรแกรมต้นฉบับ เพื่อระบุความแตกต่าง

10.4.3 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ

โจทย์ข้อที่ 1: การเปลี่ยนแปลงค่าเริ่มต้น

คำถาม:

กำหนดรหัสเทียมต้นฉบับ:

START
  SET A TO 10
  SET B TO A + 5
  PRINT B
END

คำถามย่อย: ถ้าเปลี่ยนบรรทัดที่ 1 จาก SET A TO 10 เป็น SET A TO 20 จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ติดตามค่า A และ B
  • สังเกตว่าการเปลี่ยนค่าเริ่มต้นของ A จะส่งผลต่อค่า B ที่คำนวณจาก A

เฉลย

บรรทัด คำสั่ง A B ผลลัพธ์ที่พิมพ์
START--
1SET A TO 2020-
2SET B TO A + 52025
3PRINT B202525
END

คำตอบ: 25

โจทย์ข้อที่ 2: การเปลี่ยนแปลงการดำเนินการในลูป

คำถาม:

กำหนดรหัสเทียมต้นฉบับ:

START
  SET i TO 1
  SET total TO 0
  WHILE i <= 3 DO
    total = total + i
    i = i + 1
  END WHILE
  PRINT total
END

คำถามย่อย: ถ้าเปลี่ยนบรรทัดที่ 4 จาก total = total + i เป็น total = total + (i * 2) จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ลูปยังคงทำงาน 3 รอบ (สำหรับ i เป็น 1, 2, 3)
  • การเปลี่ยนแปลงคือการคำนวณ total ในแต่ละรอบ

เฉลย

รอบ บรรทัด/คำสั่ง i total i <= 3 i * 2 ผลลัพธ์ที่พิมพ์

-SET total TO 010

i = i + 122

total = total + (i * 2)264
i = i + 136
3WHILE i <= 3 DO36True
total = total + (i * 2)3126
i = i + 1412

-PRINT total41212

โจทย์ข้อที่ 3: การเปลี่ยนแปลงเงื่อนไข IF

คำถาม:

กำหนดรหัสเทียมต้นฉบับ:

START
  INPUT score
  IF score >= 50 THEN
    PRINT "ผ่าน"
  ELSE
    PRINT "ไม่ผ่าน"
  END IF
END

คำถามย่อย: ถ้าผู้ใช้ป้อนค่า Score = 48 และเปลี่ยนบรรทัดที่ 3 จาก IF score >= 50 THEN เป็น IF score > 40 THEN จงหาผลลัพธ์ที่แสดงบนหน้าจอ

แนวคิด

  • เงื่อนไข IF เปลี่ยนไป
  • ประเมินเงื่อนไขใหม่ด้วย Input ที่กำหนด

เฉลย

  1. Start: โปรแกรมเริ่มต้น
  2. Input Score: รับค่า Score = 48
  3. IF score > 40 THEN: ตรวจสอบเงื่อนไข 48 > 40 ซึ่งเป็น True
  4. ตามเส้นทาง True ไปยังสัญลักษณ์ประมวลผล
  5. Print "ผ่าน": แสดงผล "ผ่าน"
  6. End: โปรแกรมสิ้นสุด

คำตอบ: ผ่าน

โจทย์ข้อที่ 4: การเปลี่ยนแปลงเงื่อนไข WHILE

คำถาม:

กำหนดรหัสเทียมต้นฉบับ:

แนวคิด

  • เงื่อนไข WHILE เปลี่ยนไป ทำให้ลูปอาจทำงานเพิ่มอีก 1 รอบ

10.4.4 ตัวอย่างข้อสอบฝึกทำ

โจทย์ข้อที่ 6: การเปลี่ยนแปลงค่าเริ่มต้น

คำถาม:

กำหนดรหัสเทียมต้นฉบับ:

START
  SET X TO 5
  SET Y TO X * 2
  Y = Y - 3
  PRINT Y
END

คำถามย่อย: ถ้าเปลี่ยนบรรทัดที่ 1 จาก SET X TO 5 เป็น SET X TO 8 จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ค่าเริ่มต้นของ X เปลี่ยนไป ส่งผลต่อการคำนวณ Y

เฉลย

X = 8, Y = 8 × 2 = 16, Y = 16 - 3 = 13

ผลลัพธ์คือ 13

โจทย์ข้อที่ 7: การเปลี่ยนแปลงการดำเนินการในลูป

คำถาม:

กำหนดรหัสเทียมต้นฉบับ:

START
  SET i TO 1
  SET sum TO 0
  WHILE i <= 3 DO
    sum = sum + i
    i = i + 1
  END WHILE
  PRINT sum
END

คำถามย่อย: ถ้าเปลี่ยนบรรทัดที่ 4 จาก sum = sum + i เป็น sum = sum + (i * i) จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ลูปยังคงทำงาน 3 รอบ
  • การคำนวณ sum ในแต่ละรอบเปลี่ยนไป (บวกด้วยกำลังสองของ i)

เฉลย

รอบ 1: sum = 0 + (1 × 1) = 1

รอบ 2: sum = 1 + (2 × 2) = 5

รอบ 3: sum = 5 + (3 × 3) = 14

ผลลัพธ์คือ 14

โจทย์ข้อที่ 8: การเปลี่ยนแปลงเงื่อนไข IF-ELSE

คำถาม:

กำหนดรหัสเทียมต้นฉบับ:

START
  INPUT num
  IF num % 2 == 0 THEN
    PRINT "Even"
  ELSE
    PRINT "Odd"
  END IF
END

คำถามย่อย: ถ้าผู้ใช้ป้อนค่า num = 7 และเปลี่ยนบรรทัดที่ 3 จาก IF num % 2 == 0 THEN เป็น IF num > 5 THEN จงหาผลลัพธ์ที่แสดงบนหน้าจอ

แนวคิด

  • เงื่อนไข IF เปลี่ยนไป
  • ประเมินเงื่อนไขใหม่ด้วย Input ที่กำหนด

เฉลย

num = 7, เงื่อนไข 7 > 5 เป็น True

ดังนั้นจะเข้าบล็อก THEN และแสดงผล "Even"

ผลลัพธ์คือ "Even"

โจทย์ข้อที่ 9: การเปลี่ยนแปลงเงื่อนไข WHILE

คำถาม:

กำหนดรหัสเทียมต้นฉบับ:

START
  SET count TO 0
  WHILE count < 5 DO
    PRINT count
    count = count + 1
  END WHILE
  PRINT "Done"
END

คำถามย่อย: ถ้าเปลี่ยนบรรทัดที่ 3 จาก WHILE count < 5 DO เป็น WHILE count <= 5 DO จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • เงื่อนไข WHILE เปลี่ยนไป ทำให้ลูปทำงานเพิ่มอีก 1 รอบ

เฉลย

ลูปจะทำงานเมื่อ count เป็น 0, 1, 2, 3, 4, 5 (6 รอบ)

โจทย์ข้อที่ 10: การเปลี่ยนแปลงการอัปเดตในลูป (และผลลัพธ์)

คำถาม:

กำหนดรหัสเทียมต้นฉบับ:

START
  SET x TO 10
  WHILE x > 0 DO
    PRINT x
    x = x - 2
  END WHILE
  PRINT "Finished"
END

คำถามย่อย: ถ้าเปลี่ยนบรรทัดที่ 4 จาก x = x - 2 เป็น x = x - 3 จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • การอัปเดต x เปลี่ยนไป ทำให้ลูปทำงานน้อยลง และค่าที่พิมพ์ออกมาก็เปลี่ยนไป

เฉลย

รอบ 1: PRINT 10, x = 10 - 3 = 7

รอบ 2: PRINT 7, x = 7 - 3 = 4

รอบ 3: PRINT 4, x = 4 - 3 = 1

รอบ 4: PRINT 1, x = 1 - 3 = -2

รอบ 5: x = -2 (≤ 0), ออกจากลูป

ผลลัพธ์คือ:

7
4
1
Finished
