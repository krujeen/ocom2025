บทที่ 9.2: การกำหนดค่าให้ตัวแปร (=)

การเรียนรู้เกี่ยวกับการกำหนดค่าให้ตัวแปรและการทำงานของ Assignment Operator

เนื้อหาในบทเรียน

  • 9.2.1 ตัวแปร (Variables)
  • 9.2.2 การกำหนดค่าให้ตัวแปร (Assignment Operator: =)
  • 9.2.3 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ
  • 9.2.4 ตัวอย่างข้อสอบฝึกทำ

ในบทเรียนนี้ เราจะมาเรียนรู้เกี่ยวกับ การกำหนดค่าให้ตัวแปร (Variable Assignment) ซึ่งเป็นแนวคิดพื้นฐานที่สำคัญที่สุดในการเขียนโปรแกรมคอมพิวเตอร์ การกำหนดค่าคือการนำข้อมูลไปเก็บไว้ในหน่วยความจำที่ถูกตั้งชื่อไว้ (ตัวแปร) เพื่อให้โปรแกรมสามารถนำข้อมูลนั้นไปใช้ ประมวลผล หรือเปลี่ยนแปลงได้ในภายหลัง

9.2.1 ตัวแปร (Variables)

ตัวแปร (Variable) คือ ชื่อที่ใช้สำหรับอ้างอิงถึงตำแหน่งในหน่วยความจำของคอมพิวเตอร์ที่ใช้เก็บข้อมูล ค่าของตัวแปรสามารถเปลี่ยนแปลงได้ในระหว่างการทำงานของโปรแกรม

ชื่อตัวแปร

ควรตั้งชื่อให้สื่อความหมายถึงข้อมูลที่เก็บอยู่ (เช่น score, user_name, total_amount) ใน Python นิยมใช้รูปแบบ snake_case สำหรับชื่อตัวแปร

ประเภทข้อมูล

Python เป็นภาษาแบบ Dynamic Typing ซึ่งหมายความว่าคุณไม่จำเป็นต้องประกาศประเภทของตัวแปรอย่างชัดเจนเมื่อสร้างตัวแปร ตัวแปรสามารถเก็บข้อมูลได้หลายประเภท เช่น:

  • จำนวนเต็ม (Integer)
  • จำนวนจริง (Float)
  • ข้อความ (String)
  • ค่าความจริง (Boolean)

9.2.2 การกำหนดค่าให้ตัวแปร (Assignment Operator: =)

การกำหนดค่าให้ตัวแปรเป็นการนำค่าทางด้านขวาของเครื่องหมาย = ไปเก็บไว้ในตัวแปรทางด้านซ้าย

สัญลักษณ์

= (อ่านว่า "เท่ากับ" ในทางคณิตศาสตร์ แต่ในทางโปรแกรมมิ่งมักอ่านว่า "กำหนดค่าให้" หรือ "เก็บค่า")

รูปแบบทั่วไปในภาษา Python

<variable_name> = <value_or_expression>

ตัวอย่าง

score = 100         # กำหนดให้ตัวแปร score เก็บค่า 100 (จำนวนเต็ม)
name = "Alice"      # กำหนดให้ตัวแปร name เก็บข้อความ "Alice"
price = 25.50       # กำหนดให้ตัวแปร price เก็บค่า 25.50 (จำนวนจริง)
quantity = 4        # กำหนดให้ตัวแปร quantity เก็บค่า 4
total = price * quantity # กำหนดให้ตัวแปร total เก็บผลคูณของ price กับ quantity

หลักการสำคัญของการกำหนดค่า:

  1. ค่าทางขวาถูกประมวลผลก่อน: โปรแกรมจะคำนวณหรือประเมินค่านิพจน์ทางด้านขวาของเครื่องหมาย = ให้เรียบร้อยก่อน
  2. นำผลลัพธ์ไปเก็บทางซ้าย: ผลลัพธ์ที่ได้จากขั้นตอนที่ 1 จะถูกนำไปเก็บไว้ในตัวแปรทางด้านซ้าย
  3. ค่าเดิมของตัวแปรจะถูกแทนที่: หากตัวแปรทางด้านซ้ายเคยมีค่าอยู่แล้ว ค่าเดิมนั้นจะถูกลบทิ้งไปและแทนที่ด้วยค่าใหม่

ตัวอย่างการทำงานแบบลำดับใน Python

x = 5    # x มีค่า 5
x = x + 2 # ประมวลผล x + 2 (ซึ่งคือ 5 + 2 = 7) แล้วนำ 7 ไปเก็บใน x
          # ตอนนี้ x มีค่า 7 (ค่า 5 เดิมหายไป)
print(x)  # แสดงผล 7

9.2.3 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ

เอกสารนี้รวบรวมตัวอย่างโจทย์พื้นฐานสำหรับการทำความเข้าใจการกำหนดค่าให้ตัวแปรและการติดตามการทำงานของโปรแกรม เพื่อเตรียมความพร้อมสำหรับการสอบ สอวน. คอมพิวเตอร์ครับ

โจทย์ข้อที่ 1: การกำหนดค่าพื้นฐาน

คำถาม: กำหนดรหัส Python ต่อไปนี้

a = 25
b = a + 10
print(b)

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ไล่คำสั่งทีละบรรทัดและติดตามการเปลี่ยนแปลงค่าของตัวแปร

เฉลย

บรรทัด คำสั่ง a b ผลลัพธ์ที่พิมพ์
1a = 2525-
2b = a + 102535
3print(b)253535

คำตอบ: 35

โจทย์ข้อที่ 2: การกำหนดค่าซ้ำ

คำถาม: กำหนดรหัส Python ต่อไปนี้

count = 0
count = count + 1
count = count + 1
print(count)

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • สังเกตว่าตัวแปร count ถูกกำหนดค่าใหม่ในแต่ละบรรทัด ทำให้ค่าเดิมถูกทับ

เฉลย

บรรทัด คำสั่ง count ผลลัพธ์ที่พิมพ์
1count = 00
2count = count + 11
3count = count + 12
4print(count)22

คำตอบ: 2

โจทย์ข้อที่ 3: การใช้ตัวแปรหลายตัวในการคำนวณ

คำถาม: กำหนดรหัส Python ต่อไปนี้

x = 10
y = 5
z = x * y
x = z - y
print(x)
print(z)

จงหาค่าของ x และ z ที่พิมพ์ออกมา

แนวคิด

  • ติดตามค่าของตัวแปรทุกตัวในแต่ละบรรทัดอย่างละเอียด

เฉลย

บรรทัด คำสั่ง x y z ผลลัพธ์ที่พิมพ์
1x = 1010--
2y = 5105-
3z = x * y10550
4x = z - y45550
5print(x)4555045
6print(z)4555050

คำตอบ: x = 45 และ z = 50

โจทย์ข้อที่ 4: การกำหนดค่าด้วยข้อความ

คำถาม: กำหนดรหัส Python ต่อไปนี้

first_name = "John"
last_name = "Doe"
full_name = first_name + " " + last_name
print(full_name)

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • การดำเนินการ + กับข้อความคือการนำข้อความมาต่อกัน (String Concatenation)
  • สังเกตว่ามีช่องว่าง (" ") เป็นส่วนหนึ่งของข้อความที่นำมาต่อด้วย

เฉลย

บรรทัด คำสั่ง first_name last_name full_name ผลลัพธ์ที่พิมพ์
1first_name = "John""John"--
2last_name = "Doe""John""Doe"-
3full_name = ..."John""Doe""John Doe"
4print(full_name)"John""Doe""John Doe"John Doe

คำตอบ: John Doe

โจทย์ข้อที่ 5: การสลับค่าตัวแปรโดยใช้ตัวแปรชั่วคราว

คำถาม: กำหนดรหัส Python ต่อไปนี้

a = 10
b = 20
temp = a
a = b
b = temp
print(a)
print(b)

จงหาค่าของ a และ b ที่พิมพ์ออกมา

แนวคิด

  • ติดตามค่าของตัวแปร a, b, temp ในแต่ละบรรทัดอย่างละเอียด
  • สังเกตว่านี่คือเทคนิคมาตรฐานในการสลับค่าตัวแปรโดยใช้ตัวแปรชั่วคราว

เฉลย

บรรทัด คำสั่ง a b temp ผลลัพธ์ที่พิมพ์
1a = 1010--
2b = 201020-
3temp = a102010
4a = b202010
5b = temp201010
6print(a)20101020
7print(b)20101010

คำตอบ: a = 20 และ b = 10

9.2.4 ตัวอย่างข้อสอบฝึกทำ

เอกสารนี้รวบรวมตัวอย่างข้อสอบสำหรับนักเรียนได้ฝึกทำในหัวข้อ "การกำหนดค่าให้ตัวแปร" เพื่อเสริมสร้างความเข้าใจและเตรียมความพร้อมสำหรับการสอบ สอวน. คอมพิวเตอร์ครับ

โจทย์ข้อที่ 6: การกำหนดค่าและการคำนวณลำดับ

คำถาม: กำหนดรหัส Python ต่อไปนี้

value = 100
value = value / 2  # การหารปกติจะได้ float
value = value + 15
print(value)

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ติดตามการเปลี่ยนแปลงของ value ทีละบรรทัด
  • ระวังว่าการหารด้วย / ใน Python 3 จะให้ผลลัพธ์เป็นจำนวนจริง (float) เสมอ

เฉลย

บรรทัด คำสั่ง value ผลลัพธ์ที่พิมพ์
1value = 100100
2value = value / 250.0
3value = value + 1565.0
4print(value)65.065.0

คำตอบ: 65.0

โจทย์ข้อที่ 7: การกำหนดค่าและการใช้ตัวแปรหลายตัว

คำถาม: กำหนดรหัส Python ต่อไปนี้

num1 = 7
num2 = 3
result = num1 * num2
num1 = num1 + result
print(num1)
print(result)

จงหาค่าของ num1 และ result ที่พิมพ์ออกมา

แนวคิด

  • ติดตามค่าของ num1, num2, result ในแต่ละบรรทัดอย่างรอบคอบ

เฉลย

บรรทัด คำสั่ง num1 num2 result ผลลัพธ์ที่พิมพ์
1num1 = 77--
2num2 = 373-
3result = num1 * num27321
4num1 = num1 + result28321
5print(num1)2832128
6print(result)2832121

คำตอบ: num1 = 28, result = 21

โจทย์ข้อที่ 8: การกำหนดค่าด้วยข้อความและการต่อข้อความ

คำถาม: กำหนดรหัส Python ต่อไปนี้

greeting = "Hi"
name = "Alice"
message = greeting + " " + name + "!"
print(message)

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • การดำเนินการ + กับข้อความคือการนำข้อความมาต่อกัน (String Concatenation)

เฉลย

บรรทัด คำสั่ง greeting name message ผลลัพธ์ที่พิมพ์
1greeting = "Hi""Hi"--
2name = "Alice""Hi""Alice"-
3message = ..."Hi""Alice""Hi Alice!"
4print(message)"Hi""Alice""Hi Alice!"Hi Alice!

คำตอบ: Hi Alice!

โจทย์ข้อที่ 9: การกำหนดค่าแบบลำดับและผลกระทบต่อตัวแปรอื่น

คำถาม: กำหนดรหัส Python ต่อไปนี้

a = 1
b = a + 5
a = b * 2
print(a)
print(b)

จงหาค่าของ a และ b ที่พิมพ์ออกมา

แนวคิด

  • ระวังว่าการเปลี่ยนแปลงค่าของ a ในบรรทัดที่ 3 จะไม่ส่งผลย้อนหลังต่อ b ที่ถูกกำหนดค่าไปแล้วในบรรทัดที่ 2

เฉลย

บรรทัด คำสั่ง a b ผลลัพธ์ที่พิมพ์
1a = 11-
2b = a + 516
3a = b * 2126
4print(a)12612
5print(b)1266

คำตอบ: a = 12, b = 6

โจทย์ข้อที่ 10: การกำหนดค่าและการคำนวณที่ซับซ้อนขึ้น

คำถาม: กำหนดรหัส Python ต่อไปนี้

x = 2
y = 3
z = x + y
x = y * z
y = x - z
z = y / x
print(z)

(หมายเหตุ: / คือการหารปกติ)
จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ติดตามค่าของตัวแปร x, y, z ในแต่ละบรรทัดอย่างละเอียด
  • ระวังลำดับการประมวลผลและการหารด้วย / ที่ให้ผลลัพธ์เป็น float

เฉลย

บรรทัด คำสั่ง x y z ผลลัพธ์ที่พิมพ์
1x = 22--
2y = 323-
3z = x + y235
4x = y * z1535
5y = x - z15105
6z = y / x15100.6666...
7print(z)15100.6666...0.6666...

คำตอบ: 0.6666666666666666 (หรือ 2/3)
