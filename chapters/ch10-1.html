บทที่ 10.1: การทำความเข้าใจและตีความขั้นตอนวิธี (Pseudocode หรือ Flowchart)

การเรียนรู้การวิเคราะห์และแปลความหมายของขั้นตอนวิธีจากรหัสเทียมและผังงาน

เนื้อหาในบทเรียน

  • 10.1.1 รหัสเทียม (Pseudocode)
  • 10.1.2 ผังงาน (Flowchart)
  • 10.1.3 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ
  • 10.1.4 ตัวอย่างข้อสอบฝึกทำ

ในบทเรียนนี้ เราจะมุ่งเน้นที่ทักษะสำคัญในการคิดเชิงวิเคราะห์ นั่นคือ การทำความเข้าใจและตีความขั้นตอนวิธี ซึ่งมักจะนำเสนอในรูปแบบของ รหัสเทียม (Pseudocode) หรือ ผังงาน (Flowchart) การเข้าใจวิธีการทำงานของขั้นตอนวิธีเหล่านี้เป็นสิ่งจำเป็นอย่างยิ่งในการแก้ปัญหา การวิเคราะห์ประสิทธิภาพ และการดีบักโปรแกรมในวิทยาการคอมพิวเตอร์

10.1.1 รหัสเทียม (Pseudocode)

รหัสเทียม (Pseudocode) คือ การอธิบายขั้นตอนการทำงานของโปรแกรมหรืออัลกอริทึมด้วยภาษาที่คล้ายภาษาคอมพิวเตอร์แต่ไม่มีไวยากรณ์ที่เคร่งครัดเหมือนภาษาโปรแกรมจริง ใช้คำพูดที่เข้าใจง่ายผสมกับโครงสร้างคำสั่งพื้นฐาน เพื่อให้มนุษย์สามารถทำความเข้าใจแนวคิดของอัลกอริทึมได้โดยไม่ต้องกังวลถึงรายละเอียดการเขียนโค้ด

วัตถุประสงค์:

  • เป็นสะพานเชื่อมระหว่างแนวคิดของมนุษย์กับภาษาโปรแกรม
  • ช่วยในการออกแบบอัลกอริทึมก่อนที่จะลงมือเขียนโค้ดจริง
  • ใช้ในการสื่อสารอัลกอริทึมให้ผู้อื่นเข้าใจได้ง่าย

คำสั่งและโครงสร้างพื้นฐานที่พบบ่อยในรหัสเทียม:

คำสั่ง ความหมาย ตัวอย่าง
START / END จุดเริ่มต้นและจุดสิ้นสุดของขั้นตอนวิธี START
...
END

PRINT <variable/message>

DISPLAY total

วิธีการตีความรหัสเทียม:

การตีความรหัสเทียมทำได้โดยการ แกะรอย (Tracing) ซึ่งคือการจำลองการทำงานของโปรแกรมทีละบรรทัด โดยการติดตามการเปลี่ยนแปลงค่าของตัวแปรต่างๆ อย่างเป็นระบบในตารางติดตามตัวแปร (Trace Table)

ตัวอย่างรหัสเทียม:

START
  INPUT score
  IF score >= 50 THEN
    PRINT "ผ่าน"
  ELSE
    PRINT "ไม่ผ่าน"
  END IF
END

10.1.2 ผังงาน (Flowchart)

ผังงาน (Flowchart) คือ การแสดงขั้นตอนการทำงานของโปรแกรมหรืออัลกอริทึมด้วยสัญลักษณ์ภาพมาตรฐาน ซึ่งช่วยให้เห็นภาพรวมของลำดับการทำงาน การตัดสินใจ และการวนซ้ำได้อย่างชัดเจน

วัตถุประสงค์:

  • แสดงลำดับการทำงานของโปรแกรมอย่างเป็นภาพ
  • ช่วยในการออกแบบและทำความเข้าใจตรรกะของโปรแกรม
  • เป็นเครื่องมือในการสื่อสารอัลกอริทึมที่ซับซ้อน

สัญลักษณ์พื้นฐานในผังงาน:

สัญลักษณ์ ชื่อสัญลักษณ์ ความหมาย
🔴 Terminal (เทอร์มินัล) จุดเริ่มต้น (Start) หรือจุดสิ้นสุด (End) ของโปรแกรม
📄 Input/Output (รับ/แสดงผล) การรับข้อมูลนำเข้า หรือการแสดงผลลัพธ์
📦 Process (ประมวลผล) การประมวลผล, การคำนวณ, การกำหนดค่า
🔷 Decision (ตัดสินใจ) การตรวจสอบเงื่อนไข (มีทางออก 2 ทาง: จริง/เท็จ)
➡️ Flowline (เส้นเชื่อม) แสดงทิศทางของลำดับการทำงาน

วิธีการตีความผังงาน:

การตีความผังงานทำได้โดยการไล่ตามทิศทางของลูกศรจากสัญลักษณ์หนึ่งไปยังอีกสัญลักษณ์หนึ่ง โดยดำเนินการตามคำสั่งที่ระบุในแต่ละสัญลักษณ์ และตัดสินใจตามเงื่อนไขที่พบในสัญลักษณ์ตัดสินใจ

ตัวอย่างผังงาน:

ผังงานเพื่อตรวจสอบว่าเลขเป็นบวกหรือลบ:

🔴 Start
      ↓
📄 Input X
      ↓
🔷 X > 0?
   ↙   ↘
 Yes    No
  ↓      ↓
📄 Print  📄 Print
"Positive" "Negative"
     ↘     ↙
       ↓
    🔴 End

10.1.3 ตัวอย่างโจทย์และแนวทางการทำข้อสอบ

ในส่วนนี้ เราจะมาฝึกทำความเข้าใจและตีความขั้นตอนวิธีจากรหัสเทียมและผังงาน พร้อมแนวทางการหาผลลัพธ์

โจทย์ข้อที่ 1: การตีความรหัสเทียม (ลำดับขั้นตอน)

คำถาม: กำหนดรหัสเทียมต่อไปนี้

START
  SET A TO 5
  SET B TO A * 3
  SET C TO B - 7
  PRINT C
END

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • สร้างตารางติดตามตัวแปร (Trace Table) เพื่อบันทึกค่าของ A, B, C ในแต่ละบรรทัด
  • ไล่คำสั่งทีละบรรทัดตามลำดับ

เฉลย

บรรทัด คำสั่ง A B C ผลลัพธ์ที่พิมพ์
START---
1SET A TO 55--
2SET B TO A * 3515-
3SET C TO B - 75158
4PRINT C51588
END

คำตอบ: 8

แนวคิด

  • ไล่ตามลูกศรในผังงาน
  • เมื่อเจอสัญลักษณ์ตัดสินใจ (สี่เหลี่ยมข้าวหลามตัด) ให้ประเมินเงื่อนไข (X > 0) แล้วไปตามทางที่ถูกต้อง

เฉลย

  2. Input X: รับค่า X = -3
  3. X > 0?: ตรวจสอบเงื่อนไข -3 > 0 ซึ่งเป็น False
  4. ตามเส้นทาง No ไปยังสัญลักษณ์ประมวลผล
  5. Print "Negative": แสดงผล "Negative"
  6. End: โปรแกรมสิ้นสุด

คำตอบ: Negative

โจทย์ข้อที่ 3: การตีความรหัสเทียม (การวนซ้ำ WHILE)

คำถาม: กำหนดรหัสเทียมต่อไปนี้

START
  SET count TO 1
  SET total TO 0
  WHILE count <= 4 DO
    total = total + count
    count = count + 1
  END WHILE
  PRINT total
END

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • สร้างตารางติดตามตัวแปร โดยเพิ่มคอลัมน์ "รอบ" เพื่อติดตามการวนซ้ำ
  • ในแต่ละรอบ ให้ตรวจสอบเงื่อนไข WHILE ก่อนเสมอ

โจทย์ข้อที่ 5: การตีความรหัสเทียม (เงื่อนไขซับซ้อน)

คำถาม: กำหนดรหัสเทียมต่อไปนี้

START
  INPUT age
  INPUT has_license
  IF age >= 18 AND has_license == TRUE THEN
    PRINT "คุณสามารถขับรถได้เต็มที่"
  ELSE IF age >= 18 AND has_license == FALSE THEN
    PRINT "คุณมีอายุพอ แต่ยังไม่มีใบขับขี่"
  ELSE
    PRINT "คุณยังเด็กเกินไป"
  END IF
END

ถ้าผู้ใช้ป้อน age = 20 และ has_license = FALSE จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ประเมินเงื่อนไข AND ก่อน
  • ตรวจสอบเงื่อนไข IF และ ELSE IF ตามลำดับ

10.1.4 ตัวอย่างข้อสอบฝึกทำ

เอกสารนี้รวบรวมตัวอย่างข้อสอบสำหรับนักเรียนได้ฝึกทำในหัวข้อ "การทำความเข้าใจและตีความขั้นตอนวิธี (Pseudocode หรือ Flowchart)" เพื่อเสริมสร้างความเข้าใจและเตรียมความพร้อมสำหรับการสอบ สอวน. คอมพิวเตอร์ครับ

โจทย์ข้อที่ 6: การตีความรหัสเทียม (การคำนวณสะสมในลูป)

คำถาม: กำหนดรหัสเทียมต่อไปนี้

START
  SET i TO 1
  SET product TO 1
  WHILE i <= 5 DO
    product = product * i
    i = i + 1
  END WHILE
  PRINT product
END

จงหาค่าที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ติดตาม i และ product ในแต่ละรอบของลูป while
  • product จะเก็บผลคูณสะสม

เฉลย

รอบ 1: product = 1 × 1 = 1, i = 2

รอบ 2: product = 1 × 2 = 2, i = 3

รอบ 3: product = 2 × 3 = 6, i = 4

รอบ 4: product = 6 × 4 = 24, i = 5

รอบ 5: product = 24 × 5 = 120, i = 6

รอบ 6: i = 6 (> 5), ออกจากลูป

คำตอบ: 120

โจทย์ข้อที่ 7: การตีความผังงาน (การคำนวณผลรวม)

      ↓

ถ้าผู้ใช้ป้อนค่า N = 7 จงหาผลลัพธ์ที่แสดงบนหน้าจอ

แนวคิด

  • ไล่ตามลูกศรและติดตามค่า num และ sum
  • เงื่อนไข num <= N และ num % 2 != 0

คำตอบ: 16

โจทย์ข้อที่ 8: การตีความรหัสเทียม (ลูปไม่รู้จบ)

คำถาม: กำหนดรหัสเทียมต่อไปนี้

START
  SET x TO 10
  WHILE x > 0 DO
    PRINT x
    x = x + 1
  END WHILE
  PRINT "จบ"
END

รหัสนี้จะทำงานอย่างไร? (ลูปไม่รู้จบหรือไม่) ถ้าไม่รู้จบเพราะอะไร?

แนวคิด

  • ตรวจสอบว่าตัวแปรที่ใช้ในเงื่อนไขมีการเปลี่ยนแปลงที่ทำให้เงื่อนไขเป็นเท็จได้หรือไม่

เฉลย

รหัสนี้จะทำงานเป็น ลูปไม่รู้จบ (Infinite Loop)

เหตุผล: ค่า x เริ่มต้นที่ 10 และในแต่ละรอบของลูป x จะถูกเพิ่มค่าขึ้นเรื่อยๆ (x = x + 1) ทำให้เงื่อนไข x > 0 เป็นจริงตลอดไป ไม่มีทางที่ x จะน้อยกว่าหรือเท่ากับ 0 ได้เลย

คำตอบ: ลูปไม่รู้จบ, เพราะ x จะเพิ่มขึ้นเรื่อยๆ ทำให้ x > 0 เป็นจริงตลอดไป

เฉลย

  1. Input Score, Attendance: Score = 80, Attendance = 95
  2. Score >= 80?: 80 >= 80 เป็น True
  3. Attendance >= 90?: 95 >= 90 เป็น True
  4. Print "Eligible for Bonus": แสดงผล "Eligible for Bonus"
  5. End: โปรแกรมสิ้นสุด

คำตอบ: "Eligible for Bonus"

โจทย์ข้อที่ 10: การตีความรหัสเทียม (การสลับค่าในลูป)

คำถาม: กำหนดรหัสเทียมต่อไปนี้

START
  SET A TO 0
  SET B TO 1
  SET count TO 0
  WHILE count < 5 DO
    SET next_val TO A + B
    A = B
    B = next_val
    count = count + 1
  END WHILE
  PRINT A
  PRINT B
END

จงหาค่าของ A และ B ที่แสดงผลเมื่อโปรแกรมทำงานเสร็จสิ้น

แนวคิด

  • ติดตามค่า A, B, next_val, count ในแต่ละรอบ
  • สังเกตว่านี่คือการคำนวณลำดับฟิโบนักชี
